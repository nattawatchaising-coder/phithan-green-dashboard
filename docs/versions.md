# หลายเวอร์ชัน · แบบ 3D และ BOQ (`dashboard/versions.jsx` prefix `dv`/`Dv`)

> แยกมาจาก CLAUDE.md · แก้/เพิ่มข้อตกลงของเรื่องนี้ที่ไฟล์นี้

- **แบบ 3D**: `plan3d/{jobId}` = V1 "ต้นแบบ" (ของเดิมไม่ย้าย) · เวอร์ชัน n = `plan3d/{jobId}~{n}` (`dvP3Key`) · ดัชนี `plan3dVers/{jobId}/{n}` = {name, at, by, byName, from, sum:{panels,kwp}} ("1" มีแค่ name/sum) · สร้างใหม่ = คัดลอกจากเวอร์ชันที่เลือก (ค่าเริ่ม = ต้นแบบ) · บันทึกแบบแล้ว `dvP3Saved` อัปเดต sum · `Plan3DStudio({job, ver})` ใช้ `planKey` ทั้งโหลด/บันทึก/คีย์ wizard · ลบต้นแบบไม่ได้ · ลบแบบที่มี BOQ ผูกอยู่ไม่ได้
- **BOQ**: `job.boq`/`lead.boq` = ใบที่ใช้งาน (ใบเสนอราคา/วางบิล/อื่น ๆ อ่านที่นี่เหมือนเดิม) · `boq.ver` = id เวอร์ชัน (ไม่มี = "1") · `boqVers/{jobId}/{n}` = {name, at, by, from, boq} สร้างเมื่อกดเวอร์ชันใหม่ครั้งแรก (คัดลอกใบเดิมลงเป็น "1" ก่อน) · ไม่มีโหนด = มีใบเดียว (virtual) · บันทึกใบ = `dvBoqSave` เขียน boqVers + ถ้าเป็นใบที่ใช้งานเขียน job.boq ด้วย · ปุ่ม "ใช้ใบนี้" = คัดลอกใบนั้นลง job.boq
- **BOQ ผูกแบบ 3D** ที่ `boq.plan3d` (ไม่มี = ต้นแบบ): BOQEditor อ่านแบบด้วย `dvP3Key(job.id, b.plan3d)` (ราง/ทางเดิน/ท่อ) · หัว BOQEditor มีป้ายเวอร์ชัน + ดรอปดาวน์ "แบบ 3D" (เมื่อมีแบบ > 1) · ใบเสนอราคาดึงแผงจากแบบที่ BOQ ใบที่ใช้งานผูก · สร้าง BOQ ใหม่ค่าเริ่มเลือกแบบใหม่สุดที่ยังไม่มีใบไหนผูก
- หน้าใบงาน (drawer) และใบลูกค้า (views-survey) ใช้ `useDesignVersions` ร่วมกัน: แสดงเป็น**การ์ดรายการแบบรายการใบเสนอราคา** (`DvVerCard` kind p3/boq: หัวการ์ด + ปุ่ม "ทำแบบใหม่"/"ทำใบใหม่" (ป๊อปสร้างอย่างเดียว mode "new") + "จัดการ" (เมื่อ > 1 เวอร์ชัน: เปลี่ยนชื่อ/ลบ/ใช้ใบนี้) · แถวละเวอร์ชัน แตะ = เปิดตรง · ต้นแบบ/ใบที่ใช้งานอยู่บนพื้นเข้ม ที่เหลือใหม่สุดก่อน · **ปุ่มถังขยะในแถว** (ยืนยันก่อน): แบบ 3D ลบได้ทุกอันยกเว้นต้นแบบ · มี BOQ ผูก = ปุ่มจาง · **BOQ ลบได้ทุกใบเมื่อมี > 1 ใบ** (ยืนยันด้วย `askConfirm` ของแอป ห้ามใช้ `window.confirm` — ผู้ใช้ที่เคยปิดกล่องเบราว์เซอร์ได้ false เงียบ ๆ ปุ่มกดไม่ติด · `dvBoqRemove`: ลบใบที่ใช้งาน = ใบใหม่สุดที่เหลือเป็นใบที่ใช้งานแทน) · การ์ด/ป๊อปจัดการ BOQ ไม่โชว์ป้าย "ใช้งาน · ใบเสนอราคาดึงใบนี้" และไม่มีปุ่ม "ใช้ใบนี้" แล้ว (ผู้ใช้: ใบเสนอราคาไม่ต้องผูก · ข้างในยังมี job.boq เป็นใบที่ใช้งาน) · รายการ BOQ เรียงใหม่สุดก่อน · ยังไม่มี BOQ ปุ่ม "ถอด BOQ" เปิดใบแรกตรง) · `DvRowWrap` ไม่ได้ใช้แล้ว · `movePlan3d` (ลูกค้า→งาน) ย้ายทุกเวอร์ชัน + ดัชนี + boqVers
- versions.js โหลดหลัง plan3d2.js ก่อน drawer/views-survey/sales/app
