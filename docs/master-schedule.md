# Master Schedule งานโครงการ (`dashboard/master.jsx`)

> ผู้ใช้ขอ 13 พ.ย. 2026: "Master Schedule ของงานโครงการ มาใส่ในงานที่เป็นงานติดตั้งแล้ว" · ส่งไฟล์ตัวอย่าง `Simple-Project-Plan-Template-2026.xlsx` ให้ยึดหน้าตา

## อยู่ตรงไหน
- การ์ด **Master Schedule** ในใบงาน แท็บภาพรวม ใต้การ์ดนัดหมายและทีม — **เฉพาะ `job.type === "project"`** (`drawer.jsx` → `window.MsCard`)
  - การ์ด = วง % รวม + แกนต์ย่อเฉพาะหัวข้อใหญ่ · กดเปิดหน้าต่างเต็ม (`MsModal` · portal ไป body เพราะลิ้นชักมี transform · zIndex 115)
  - แก้ได้เมื่อ `!roMode && onEdit` (โหมดฝ่ายขออนุญาต/ฝ่ายขายดูอย่างเดียว)

## หน้าตา (ตามไฟล์ตัวอย่าง)
- หัวสรุป: วง % รวม · เริ่ม/จบ/รวมกี่วัน/เหลือกี่วัน (เลยกำหนด = แดง) · กล่อง งานทั้งหมด · เสร็จแล้ว · กำลังทำ · ยังไม่เริ่ม · ล่าช้า (โชว์เมื่อมี)
- ตาราง: ID (1, 1.1) · งาน + ผู้รับผิดชอบ · เริ่ม · จบ · แถบ % · ป้ายสถานะ — **แถบแกนต์เดียวต่องาน = ช่วงแผน ระบายทับตาม %** (ไม่มีแถบ "ทำจริง" แยก)
  - หัวแกนต์: เดือน · สัปดาห์ที่ (นับจากสัปดาห์ที่โครงการเริ่ม จันทร์–อาทิตย์) · วันที่ + วันในสัปดาห์ (เมื่อช่วง ≤ 7 สัปดาห์) · แรเงาวันอาทิตย์ · เส้นแดงวันนี้
  - จอ > 1180 ครบทุกคอลัมน์ · 860–1180 ตัดคอลัมน์เริ่ม/จบ · ≤ 860 เหลือ งาน + %
- สถานะคิดเอง: 100% = เสร็จแล้ว · เลยวันจบแผนและยังไม่ 100 = **ล่าช้า** · > 0 = กำลังทำ · 0 = ยังไม่เริ่ม
- % หัวข้อใหญ่ / % รวม = ถ่วงตามจำนวนวันแผนของงานย่อย
- **ดู / ออก PDF**: A3 แนวนอน (`msPrintHTML` → `SuReportView`) ชื่อไฟล์ `MS_รหัสโครงการ_ชื่อโครงการ_วัน-เดือน-ปี` (`rpFileName(job, "MS")`) · ช่วง ≤ 12 สัปดาห์ หัวรายวัน ยาวกว่านั้นหัวรายสัปดาห์ · body กว้างคงที่ 1500px

## ข้อมูล
- `masterSchedule/{jobId}` = `{ rows: [{id, th, head, owner, planStart, planEnd, pct, link}], updatedAt, byName }` · บันทึกด้วยปุ่ม "บันทึก" ทีเดียวทั้งแผน (`set`)
- ยังไม่เคยบันทึก = โชว์แม่แบบ `MS_TEMPLATE` (เริ่มโครงการ · ออกแบบ · ขออนุญาต · จัดซื้อ & ขนส่ง · งานติดตั้ง · ทดสอบ & เชื่อมต่อ · ส่งมอบงาน)
- หัวข้อ `link: "install"` (งานติดตั้ง): **งานย่อยดึงสดจากตารางขั้นงานของรายงานประจำวัน** (`useDailyReports` → `dailyPlan` หรือใบล่าสุดถ้าใหม่กว่า · หัวข้อใหญ่ของตารางขั้นงาน 1 แถว ช่วงวัน/% รวมขั้นย่อย) ไม่เก็บซ้ำ — ช่างอัปเดต % ที่รายงานประจำวันที่เดียว · ยังไม่มีตาราง = ใช้วันนัดติดตั้ง (`job.stageDates.install`) และแก้ % ในแผนนี้เองได้ · ผู้รับผิดชอบ = `job.contractor` หรือ "ทีมติดตั้ง"
- ตัวแก้: ใส่ "วัน" แล้ววันจบคิดให้ · เปลี่ยนวันเริ่มแล้ววันจบเลื่อนตามคงจำนวนวัน · ผู้รับผิดชอบมีรายชื่อแนะนำ (วิศวกร เซลล์ ช่าง ทีมรับเหมา ฝ่ายต่าง ๆ ลูกค้า การไฟฟ้า) · ปุ่มคืนแม่แบบ/ทิ้งที่แก้ใช้ `askConfirm`

## ทดสอบ
- ใช้ฐานในหน่วยความจำสำหรับ path ที่มี `__fake` + กันเขียน path อื่น แล้ว mount `DetailDrawer` + `ConfirmHost` ด้วยงานปลอม `type: "project"` (ดู `docs/job-drawer.md`) · ใส่ `dailyPlan/__fake` ปลอมเพื่อดูแถวงานติดตั้ง
