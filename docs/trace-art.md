# แปลงรูปแบบของผู้ใช้เป็นเส้นในชุดแบบ (`tools/trace-art.mjs`)

**ผู้ใช้สั่ง 2026-11-02: "จำวิธีนี้ไว้ ใช้ได้เลย"** — ใช้เมื่อผู้ใช้ส่งรูปแบบ CAD (ลายเส้นขาวดำ) แล้วขอให้แผ่นในชุดแบบ "เหมือน 100%"
- **อย่าลอกวาดมือเป็นพิกัด** — รายละเอียดต่อลงดินลอกมือ 2 รอบ ผู้ใช้ให้ -20 และ -10 "ยังไม่เหมือน" · ลองแปลงรูปเป็นเส้นแล้วผู้ใช้ยอมรับ
- ส่วนที่ต้องเปลี่ยนตามงาน (จำนวนอินเวอร์เตอร์ ขนาดสาย ฯลฯ) ยังวาดด้วยโค้ดเหมือนเดิม · แปลงเฉพาะรูปรายละเอียดตายตัว (รายละเอียดติดตั้ง หางปลา แคลมป์ ฯลฯ)

## ขั้นตอน
1. ผู้ใช้ส่งรูปมาในแชท ได้ไฟล์ที่ `…/scratchpad/../images/<n>.png` · ขอรูปที่ครอปเฉพาะส่วนนั้น และความละเอียดสูง (กว้าง ~900–1000 px ขึ้นไป) · copy ไปไว้ในโฟลเดอร์ชั่วคราว เช่น `__ref/` (ห้าม commit และลบเมื่อเสร็จ)
2. แปลงด้วยคำสั่ง `node tools/trace-art.mjs dashboard/<ไฟล์>.js NAME=รูป.png NAME2=รูป2.png …` (ชื่อซ้ำกับที่มีอยู่จะทับของเดิม — รวมทุกรูปของไฟล์นั้นในคำสั่งเดียว)
   - ได้ `window.DS_ART[NAME] = { w, h, q, d }` · ไฟล์นี้ห้ามแก้มือ
   - ไฟล์ใหม่ต้องเพิ่ม `<script src="dashboard/<ไฟล์>.js?v=1">` ใน index.html ก่อน `build/dwgset.js` และบัมป์ด้วย `node tools/bump.js <ไฟล์>`
3. ดูผลก่อนวางลงแผ่น: ทำหน้า `__ref/prev.html` วาด `DS_ART[k]` เป็น SVG (เส้นเทาใช้ #999) เปิดใน localhost:8765 แล้วขยายดู ตัวอักษรครบไหม เส้นเรียบไหม
4. วางลงแผ่นใน `dwgset.jsx` ด้วย `D.art(NAME, x0, y0, s, ชั้นดำ, ชั้นเทา)` (มีใน `dsPx`) · `x0,y0` = มุมซ้ายบนของรูปในพิกัดแผ่น · `s` = รูปย่อกี่เท่า (พิกเซลรูป ÷ หน่วยแผ่น)
   - หาค่า `s`: วัดของที่รู้ขนาดในรูป (เช่น กรอบ = เส้นนอน/ตั้งที่ยาวที่สุดใน d) เทียบกับขนาดที่ต้องการในแผ่น
   - ชั้นเทาใช้ `DL("cell")`
5. เปิดดูในแผ่นบน localhost ก่อน (ทั้งแผ่นและซูม) ระวังทับส่วนอื่นหรือกรอบชื่อแบบ → build → บัมป์ → commit → ตรวจเว็บจริง

## ตัวแปลงทำอะไร (ถ้าผลไม่ดีให้แก้ตรงนี้)
- ถอด PNG เอง (8 bit gray/RGB/RGBA ไม่ interlace) ใช้ zlib ไม่มี dependency
- **จุดที่มืดกว่า TH = 190** นับเป็นเส้น (เปลี่ยนได้ด้วย env `TH=`) → ทำเส้นให้บางเหลือ 1 px (Zhang-Suen) → ไล่เป็นสาย
  - ใช้เพื่อนบ้านแบบ m-adjacency: เส้นเฉียงขั้นบันไดจะไม่ถูกนับเป็นทางแยก
- เส้นปิด (หัว=ท้าย) แบ่งครึ่งก่อนลดจุด — ไม่งั้นทั้งห่วงยุบเป็นจุด (ตัว O D P เคยหาย)
- **ทำให้เรียบ** (ผู้ใช้ "เส้นไม่เรียบเนียน"):
  - ย้ายจุดไปกลางเส้นจริง ถ่วงด้วยความเข้มรอบ ๆ 3×3 จากรูปเดิม
  - เฉลี่ยกับจุดข้างเคียง 1-2-3-2-1 ไม่ข้ามมุมที่หักเกิน ~45°
  - ลดจุดด้วย Douglas-Peucker tol 0.4
  - เส้นยาว ≥ 8 px ที่เอียงไม่เกิน ~1.4° ดัดให้ตรงแนวนอน/ตั้ง
  - เก็บพิกัดละเอียดครึ่งพิกเซล (q = 2)
- ทิ้งเส้นที่สั้นกว่า 1.5 px · จุดเดี่ยวเก็บเป็นจุด (เช่น จุดใน "sq.mm.")
- **เส้นเทา:** ค่าความสว่างเฉลี่ยตามเส้น > 130 (ตั้งรายรูปได้ `NAME=รูป.png@170`) · เส้นเทาในรูปต้นแบบอยู่ราว 140–160 ส่วนเส้นดำบางที่ขอบเบลออยู่ ≤ 120
  - ถ้าตั้งไว้ต่ำ (เคยใช้ 95) ขาตัว I และ T บางตัวจะกลายเป็นเทาและเกือบมองไม่เห็น
- ขนาดไฟล์ประมาณ 5–11 KB ต่อรูป

## ตัวหนังสือในรูป → ข้อความจริง (ผู้ใช้ขอ 2026-11-02)
- ตัวแปลงทำตัวหนังสือเป็นลายเส้น · ใส่กรอบข้อความใน `DS_ART_TX` (dwgset.jsx) ทุกรูปใหม่: `[ซ้าย, บน, ขวา, เส้นฐาน, ข้อความ, 1=กึ่งกลาง]` พิกัดพิกเซลรูป
- `D.art` ซ่อนเส้นที่อยู่ในกรอบทั้งเส้น (ล่างเผื่อหางตัว q 40%) แล้ววาดข้อความจริง · สูง = สูงตัวพิมพ์ใหญ่ ÷ 0.7 แต่ไม่กว้างเกินกรอบ (ตัวหนังสือจริงกว้างกว่าฟอนต์ CAD เดิม เคยทับเส้นชี้)
- ทั้งสองแผ่นต่อลงดินส่ง `minH = PG_TS.cell` ให้ป้ายเท่าป้ายที่โค้ดวาด (ผู้ใช้ "ตัวหนังสือนี้มันเล็กไป") · ป้ายที่เส้นชี้อยู่ขวาใส่ธง 2 = ชิดขวา ขยายไปทางซ้ายไม่ทับเส้น
- หากรอบ: วาด DS_ART เป็น SVG ในหน้า `__ref/` · หากลุ่มเส้นสั้น (กว้าง ≤28 สูง ≤30) ที่ชิดกันเป็นบรรทัด แล้วตีกรอบให้ดูด้วยตา ตัวเดี่ยว (A B C D ท้าย DETAIL) มักหลุด ต้องขยายกรอบเอง
- ตรวจด้วยสคริปต์: ไม่ควรมีเส้นสั้นที่คร่อมกรอบแต่ไม่ถูกซ่อน (เศษตัวหนังสือค้าง)
- คำสะกดตามรูปต้นแบบ (RIAL · PERFORRATE) — ยังไม่ได้แก้

## กรอบรูปเท่ากัน (ผู้ใช้ "ปรับกรอบให้เท่ากันทั้ง 4")
- `D.art(..., fr)` fr = { f: กรอบในรูป [ซ้าย บน ขวา ล่าง] px, x, w, h } ซ่อนเส้นกรอบเดิม (ทุกจุดอยู่บนขอบ) วาดกรอบใหม่ด้วยโค้ด · รูปเลื่อนลงครึ่งที่เพิ่ม · ป้าย DETAIL ชิดล่าง · ชื่อรูปกลางกรอบ (กรอบข้อความชื่อ = ซ้าย-ขวาของกรอบรูป)
- แผ่น GROUNDING DIAGRAM: DETAIL A–D กรอบ 274×131 เรียงห่าง 15

## ข้อจำกัด
- ข้อความที่ต้องเปลี่ยนตามงานยังวาดด้วยโค้ดแยก (`D.tx`) ไม่ใช่ใน DS_ART_TX
- รูปต้นแบบไม่ได้เก็บใน git — จะแปลงใหม่ต้องขอรูปจากผู้ใช้อีกครั้ง
