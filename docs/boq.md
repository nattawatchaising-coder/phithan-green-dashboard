แถบของที่ยังไม่มีในคลังนับด้วย · **SPD/DC MCB เป็นชุด แรงดัน + จำนวนขั้ว ↔ kA/A** (pairs + `poles`/`poleDef` → [{v, p, a}] ข้อความ "385 3P+N: 40" · `dcSpd2` Imax · `dcSpd12` Iimp · `acSpd2` · แถบบันทึกติดล่างเมื่อมีที่แก้ · ของที่มีขาย = ชิป (`BrChips`) / ตารางแรงดัน (`BrPairs`) · เงื่อนไข = ช่องตัวเลขหน่วยในหลุม + ปุ่มคืนค่ารายแถว · **ชื่อใน brStockNeeds ต้องตรงกับที่ boq.jsx ตั้ง** · **BOQ ด่วน** (ปุ่มในการ์ด BOQ · **งานบ้านเท่านั้น** (`job.type === "home"`) งานโครงการถอดแบบละเอียดตามเดิม · Accessories เผื่อ 15% (กฎ `accQuick` · ใบที่ตั้ง % ไว้แล้วไม่ทับ) · `dvs.quickBoq` versions.jsx → `BOQEditor quick`): ป๊อปเดียว ขนาด kWp/จำนวนแผง · รุ่นแผง · อินเวอร์เตอร์ · หลังคา · ระยะสายต่อเส้น · ค่าแรงเหมา ฿/W (จำเรตล่าสุด `localStorage.boq_quick_rate`) · กำไร % → ราคาขายทันที · **เป็นตัวแก้ตัวเดียวกัน** (state/เอฟเฟกต์เลือกสาย-ตู้ไฟ/สูตรเดิม แค่ return หน้าตาย่อ `qOn`) แถวแผงจัดให้เอง (แบบ 3D ถ้าจำนวนตรง ไม่งั้นแถวละ 12) · "เปิดแบบละเอียด" = ใบเดิมในหน้าเต็ม · **ใบใหม่ยังไม่เลือกรุ่นแผง/อินเวอร์เตอร์ให้** (ด่วนใบใหม่ `quickNew` หรือใบแรกของงาน `fresh` จาก versions.jsx ทั้งด่วนและละเอียด · `qPick` ธงแยก เพราะอินเวอร์เตอร์ "" = ไมโคร · ซ่อนราคา+กันบันทึกจนเลือกครบ · กด "เปิดแบบละเอียด" แล้วหน้าเต็มก็ยังว่าง/กันบันทึกเหมือนกัน) · งานที่มีใบแล้ว = สร้างเวอร์ชัน "BOQ ด่วน" ตอนกดบันทึกเท่านั้น และเป็นใบที่ใช้งานเลย (ไม่มีช่องติ๊ก) · **ฟังก์ชันใน BOQEditor ที่เรียกแบบ `X({...})` ใน JSX ห้ามมี hook** (โหมดด่วนไม่ render ส่วนนั้น hook นับไม่ตรง — FitList เคยพัง)
ราคาดึงจากคลังด้วย "ชื่อตรงกันทุกตัวอักษร" — ชื่อรายการอัตโนมัติต้องตรงกับชื่อในคลัง (`stock/IV-n`, sku `ELC-nnnn`, cat `electrical`)

### ตู้ไฟ — งานโครงการ
- **MCCB/ACB เป็น 3P ทุกตัว** (ผู้ใช้ · ทั้ง 1 และ 3 เฟส) · **MCCB ที่มีขาย = ตาราง เฟรม AF ↔ ขนาด AT + kA (Icu) ต่อเฟรม แยกสองตาราง** (ผู้ใช้): `mccbMain` เมนตู้ AC (รุ่นปรับตั้งได้ TM-D เช่น Schneider EasyPact CVS · Shunt trip เป็นอุปกรณ์เสริมแยก) · `mccbInv` อินเวอร์เตอร์ (pairs · kA ในช่อง h · `RULES.mccbAtMain/mccbAtInv` คิดใน setRules · `brkSet(ib, w)` w = main/inv) → เลือก AT แรกที่ ≥ Ir แล้ว AF เล็กสุดที่มี AT นั้น (`mccbFrame`) ชื่อ `mccbName(at, w, lsig)`: อินเวอร์เตอร์ `MCCB 3P 100AF 63AT 25kA` · เมน ต่อท้าย ` TM-D` (กันชื่อชนรุ่นอินเวอร์เตอร์ที่ AF/AT/kA เท่ากัน · ≥ gfLsigAt = ` LSIG`) ใช้ทั้ง BOQ/SLD (`mccbName0` ไม่มีส่วนท้าย)/แถบยังไม่มีในคลัง · ACB ยังเป็น `ACB 3P 1600AT` · เบรกเกอร์: MCCB ปรับตั้งได้ Ir = กระแสออก × 1.05 ปัดขึ้นทีละ 5 A (84 A → 100AT ตั้ง 90 A) แล้วคิดสายจาก Ir · รายการถึง 1250AT เกินนั้นใช้ ACB 1600–4000
- สายเล็กกว่าเบรกเกอร์ = แนะนำสาย ไม่ลดเบรกเกอร์ให้เอง (ปุ่ม "ใช้สายตามเบรกเกอร์")
- ระบบล่อฟ้า (ไม่มี / มี·แผงห่างพอ / มี·แผงใกล้) — "แผงใกล้" = SPD Type 1+2 ทั้ง AC และ DC
- ฟิวส์ใบมีด NH00 กันหลัง AC SPD: Type 2 = 32 A · Type 1+2 = 125 A (ไม่ต้องมีถ้าเมน ≤ 125AT)
- Ground Fault: GFR + ZCT + Shunt trip เมื่อเมน < 1000AT — MCCB เมนจากตาราง `mccbMain` + บรรทัด **`MCCB CVS Shunt Trip (MX) 220VAC`** แยก (คอยล์ MX LV429387 ในคลัง · ผู้ใช้: CVS ไม่มี Shunt trip ในตัว ต้องซื้ออุปกรณ์เสริม) — **ใส่ต่อจาก MCCB เมนงานโครงการทุกครั้ง ไม่ขึ้นกับ Ground Fault** (ยกเว้น LSIG) · ≥ 1000AT ใช้ trip unit LSIG · Power Meter PM2230 + CT ตามเมน · MCB 6A กันสายวัด · ปิดได้ทีละอย่าง
- ใบรายการแยกหมวดละตู้: ตู้ไฟ AC / ตู้ไฟ DC / ตู้ไฟ DATA LOGGER

### ตู้ไฟ — งานบ้าน (คิดแบบงานโครงการ แต่ต่างตรงนี้)
- ไม่มีกลุ่ม COMBINER BOX แล้ว · ไม่มีหัวข้อโครงสร้างรองรับอุปกรณ์
- อินเวอร์เตอร์ตัวเดียว = เบรกเกอร์ตัวเดียว ต่อเข้าเลย ไม่มีเมนแยก
- เบรกเกอร์ = **MCB + RCCB** (ผู้ใช้ ต.ค. 2026: ของที่มีขายมีแต่ RCCB · ไม่ใช้ RCBO แล้ว) · MCB ขนาดแรก ≥ fixK × กระแส จาก `mcbHome2P`/`mcbHome3P` ชื่อ `MCB 2P 32A` · RCCB ขนาดแรก ≥ MCB จาก `rccb2P`/`rccb4P` (25/40/63) ชื่อ `RCCB 40A 2P 100mA` / `RCCB 40A 4P 100mA` (รุ่นกระแสรั่วกฎ `rcboMa` คีย์เดิม ปุ่ม 30/100/300) · RCCB เฉพาะเบรกเกอร์ตัวแรกฝั่งกริด (เมน หรืออินเวอร์เตอร์ตัวเดียว) ลูกย่อยต่ออินเวอร์เตอร์เป็น MCB อย่างเดียว · ใหญ่เกินรายการ = MCCB · ใช้ทั้ง BOQ (`brkPickHome`)/SLD/แถบของที่ยังไม่มีในคลัง
- กันหลัง SPD ด้วย `MCB 2P 32A` / `MCB 3P 32A` (ไม่ใช้ฟิวส์)
- ตู้ไฟ DC มี **DC MCB สตริงละ 1 ตัว** ขนาดแรก ≥ dcMcbK × Isc (ค่าเริ่ม 1.5 ตาม IEC 62548 · 10/16/20/25/32/40/50/63 A) ชื่อ `DC MCB 20A 2P 800VDC` — แรงดันพิกัดเลือกตัวแรก ≥ Voc สตริง × vocK จากกฎ `dcMcbV` (500/800/1000) (เพิ่มจากฟิวส์ + SPD)
- ไม่มี Ground Fault / PM2230 · ไม่มีตัวเลือกระบบล่อฟ้า (SPD Type 2 เสมอ)
- สายไฟงานบ้านคิดจาก 1.25 × กระแส

### อื่น ๆ
- **Voc สตริงคิดที่อุณหภูมิต่ำสุด** กฎ `tMin` (ค่าเริ่ม 15°C · หน้าตั้งค่า BOQ ตู้ไฟ DC) ใช้ทั้ง BOQ `stringConfig` (tcVoc แผง ไม่มี = −0.25) · ออกแบบระบบ `scTMin` (solarcalc) · SLD — จำนวนแผงต่อสตริงสูงสุดลดลงตาม
- **ตรวจสตริงกับอินเวอร์เตอร์** (`stringConfig` boq.js · ตรงกับ solarcalc `scCurrent`): Imp 1 สตริง ≤ `maxInA` · Imp × `strPerMppt` ≤ `maxMpptA` (ไม่มี = maxInA) · Isc × สตริง/MPPT ≤ `maxIscA` (**ไม่คูณ 1.25** ผู้ใช้ ต.ค. 2026 · 1.25 ใช้แค่เลือกสาย PV `pvWireK` · การ์ดกระแส DC ใน BOQ โชว์ Isc ตรง ๆ) · **Vmp ตอนเซลล์ร้อน** กฎ `tCellHot` (65°C · tcVmp ไม่มี = tcVoc) → minSeries + เตือนแรงดันหลุดใต้ MPPT (ออกแบบระบบใช้ค่าเดียวกันผ่าน `scTHot`) · **แผงสองหน้า** (`panel.bifacial` ช่องในคลัง · ไม่ระบุ = เดาจากชื่อรุ่น BDV/HBD/DEG/JAM..D..) Isc × กฎ `bifacialK` 1.1 → `scfg.iscD` ใช้เลือกสาย PV/ฟิวส์/DC MCB · กฎสาย `pvWireMin` 6 · `pvWireTempK` (ตาราง PV อ้างอิง 60°C) · `acTempK` คูณเข้า pickWireSize/ampacityOf (ตาราง วสท. 40°C) · แบต S1 `battS1Kwh`/`battS1Per`
