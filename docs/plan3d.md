# ตัวออกแบบหลังคา/วางแผง (`plan3d/{jobId}` · `dashboard/plan3d2.jsx`)

> แยกมาจาก CLAUDE.md — ตัวแก้ 2D · ขั้นพาทำ · หลังคา · สิ่งบดบัง · วางแผง · แก้/เพิ่มข้อตกลงของเรื่องนี้ที่ไฟล์นี้

- **ตัวแก้ตัวเดียว** `dashboard/plan3d2.jsx` `Plan3DStudio` — แก้บนผัง 2D (SVG) ทับภาพดาวเทียม/โดรน · 3D ไว้ดูผลและเงาเท่านั้น · ใช้ helper เรขาคณิตของ plan3d.jsx ทั้งหมด จึงต้องโหลด **หลัง** plan3d.js · ชื่อระดับโลกใช้คำนำหน้า `p3s`/`P3S`
- **ตัวแก้แบบเก่า (`Plan3DEditor`) เอาออกแล้ว** (ต.ค. 2026) — `plan3d.jsx` เหลือเอนจินเรขาคณิต/แผง (`p3Panels` `p3RoofSurf` `p3FillBlk` ฯลฯ ใช้ทั้งตัวแก้ · BOQ · worker คำนวณเงา) + `usePlan3d` · `P3_CSS`/`P3Icon`/`P3NumRange` (หน้าออกแบบระบบใช้) · `P3MapPicker` · ไลบรารีส่งออก DXF/ชุดแบบ/SLD (`p3Dxf` `p3Sld` `p3ExportSet` …) เรียกจากปุ่ม **"ชุดแบบ DXF"** ในหน้าออกแบบระบบ (ดูข้อขั้น 8) · `Plan3DEntry` = `Plan3DStudio` ตรง ๆ (ไม่มี `p3_editor` แล้ว)
- ข้อมูลที่แบบเก่าเคยตั้ง (โดม · `grp` · ความสูงมุม) ยังอ่าน/วาด/นับแผงได้ตามเดิมเพราะอยู่ในเอนจิน — แบบใหม่ต้องเก็บฟิลด์ที่ไม่รู้จักไว้ครบเหมือนเดิม
- **ต้องเก็บฟิลด์ที่ตัวเองไม่รู้จักไว้ครบ** (โหลดแบบ merge แก้ทีละฟิลด์ ห้ามสร้างก้อนใหม่) ไม่งั้นข้อมูลที่ตั้งในแบบเก่า/`sys` หาย · หลังคาที่มี `grp` ลากย้ายไปพร้อมกันทั้งกลุ่ม
- หลังคาทรงอิสระ: ความสูงจริงอยู่ที่ `ph[]` (h = 0.05) · หลังคาเพิงเก็บขอบชายคาไว้ที่ `p3sLow`
- หาขอบอัตโนมัติ (ค่าเริ่ม) = อ่านขอบในภาพ (Sobel `p3sEdgeField`) แล้วยิงหาขอบ 4 ทิศ (`p3sRayRect`) — ไม่ขึ้นกับสีหลังคา ใช้กับหลังคาสีเข้มได้ · โหมด "ไล่สี" (`p3sTrace`) ยังเลือกได้ · ทั้งหมดคิดในเครื่อง ไม่ส่งภาพออก
- แนวหลังคา `st.p3sAxis` (องศา −45..45, ระดับบนสุด) — ผังหมุนตามแนว กริด/สี่เหลี่ยม/การดูดฉากตามแนวนี้ · `az` ของหลังคายังเป็นทิศจริงเสมอ
- ทางเดิน `roof.walks = [{id, w, pts:[{x,z}] สัมพัทธ์กับ roof.x/z}]` — เอนจิน `p3WalkCut` (plan3d.jsx ใน `p3Panels`) ตัดแผงที่ทับแนวออก ดังนั้นนับแผง/BOQ ตรงทั้งสองตัวแก้ · ทางเดินเป็นช่วงเท่า ๆ กัน = `gc/gr/gg` ของชุดแผง
- โหมด **พาทำทีละขั้น** (การ์ดบนสุดของแผงขวา, **บังคับเสมอ ปิดไม่ได้ · ข้ามขั้นไม่ได้ ย้อนกลับได้อย่างเดียว** — ไปได้ไกลสุดถึงขั้นแรกที่ยังไม่เสร็จ `reach` · ขั้นไม่บังคับ (สิ่งบดบัง/ทางเดิน) กด "ไม่มี · ไปต่อ"): 8 ขั้น ภาพ → พื้นที่ติดตั้ง (`st.p3sArea.pts` ลากกรอบ ใช้ซูมและหาแนวอัตโนมัติในกรอบ) → แนว → **หลังคา + ความสูง/ความชัน (ขั้นเดียว)** → สิ่งบดบัง → แผง → 3D/บันทึก → **ออกแบบระบบ · ผลผลิต** (ขั้นทางเดินเดิมเอาออกแล้ว — ทางเดินระหว่างแผงใช้ "แบ่งโซน" ในการ์ดหลังคา) · กดขั้น = เปิดเครื่องมือของขั้นนั้น **เครื่องมืออื่นถูกล็อก** (`wizAllowRef`: เลื่อนภาพ + เครื่องมือของขั้น · ตั้งแต่ขั้นหลังคาเพิ่ม เลือก (ไม่มีวัดระยะแล้ว) · คีย์ลัดก็ล็อก) · **ไม่เด้งไปขั้นถัดไปเอง** ทำเสร็จแล้วผู้ใช้กดถัดไปเอง (แก้ซ้ำได้) · ขั้นแนวซ่อนการ์ดแนวเดิม · ขั้นแนวถาม "ตรงไหม" ±1° แล้ว "ตรงแล้ว ไปต่อ" · ปุ่มย้อน/ถัดไปติดล่างแผงขวา · ขั้นที่ข้ามได้จำไว้ที่ `p3s_wiz2_{jobId}` ด้วยชื่อขั้น (`k`: obs/fin ไม่ใช่เลขลำดับ) ไม่เขียนลงข้อมูลงาน
- หลังคาที่วาดใหม่ในตัวแก้แบบใหม่ **ยังไม่มีแผง** (`roof.noPanel = true` — เอนจิน `p3Panels` คืน 0 แผง ใช้ทั้งสองตัวแก้และ BOQ) แผงขึ้นเมื่อกด "วางแผงเต็มหลังคา" · ปุ่ม "เอาแผงออกจากหลังคานี้" ตั้งกลับ · แบบเก่ายังไม่มีปุ่มปลด noPanel
- วาดหลังคา: **ราบ/เพิง/จั่ว/ปั้นหยา/ครึ่งวงกลม = สี่เหลี่ยมเสมอ** (ไม่มีปุ่มเลือกรูปร่างแล้ว) · ทีละผืน = คลิกหลายจุด · หาขอบอัตโนมัติใช้ได้ทุกทรงยกเว้นทีละผืน ป๊อปผลลัพธ์สลับทรงได้ (พรีวิวเส้นสัน/ตะเข้/แนวโค้ง) ก่อนกด "เอาหลังคาแบบนี้"
- เข้าขั้นวาดหลังคา = **ป๊อปเลือกทรงเด้งก่อนเสมอ** (`kindPick`, เปิดซ้ำได้จากปุ่ม "ทรง: …" ในการ์ดพาทำ) · ในขั้นนี้แถบทรง/หาขอบบนผังโชว์ตลอดแม้เผลอกดไปเครื่องมือเลือก (มีปุ่ม "กลับไปวาดหลังคา") · Esc ไม่หลุดจากเครื่องมือวาด · กลับจาก 3D ได้เครื่องมือของขั้นคืน (`wizHomeRef`)
- หาขอบอัตโนมัติ **แตะหลายจุดได้**: ได้ผลแล้วแตะส่วนอื่นของอาคาร → รวมเป็นสี่เหลี่ยมเดียวครอบทุกผลตามแนวหลังคา (`p3sMergeRect`, `trace.parts`) · ปุ่ม "ย้อนจุดล่าสุด" · **หมุนกรอบ** ±1°/±5°/0° ในป๊อป (`trace.rot` — จุดเดียวหมุนรอบจุดกลาง `p3sRotPts` · หลายจุดรวมกรอบใหม่ตามแนว+มุมหมุน)
- **เพิ่มหลังคาอีกหลัง**: กดใช้ผลหาขอบแล้วโหมดหาขอบยังเปิด ขึ้นป๊อป "เพิ่มหลังคาแล้ว N หลัง" แตะหลังถัดไปได้ทันที (`trace.done`) · ปุ่ม "เพิ่มหลังคา" ในการ์ดพาทำ/แถบบนผัง/ป๊อป = `addRoof` ล้างของค้างแล้วเด้งเลือกทรงของหลังใหม่ · ป๊อปหาขอบ/เพิ่มหลังคาขึ้นเมื่อไร แถบบนผังซ่อน (ไม่ซ้อนกัน)
- **แถบเครื่องมือบนผังขั้นวาดหลังคาโชว์เฉพาะตอนกำลังเพิ่ม** (`roofArm`: เลือกทรงแล้ว → วาดเสร็จหายไป · ยังไม่มีหลังคาก็โชว์) · ป้ายชื่อหลังคาบนผังเป็นเม็ดยาเห็นทุกระดับซูม
- **ขั้น 4 = "วาดหลังคา · ความสูงและความชัน"** (รวมขั้นวาดกับขั้นความชันเดิม): ไม่มีแถวปุ่ม "ทรง/หาขอบ" ในการ์ดแล้ว (เลือกทรงในป๊อป `kindPick` — ป๊อปเด้งเองเฉพาะตอนยังไม่มีหลังคา · มีปุ่ม "ครบแล้ว · ไม่เพิ่มหลังคา") · มีหลังคาแล้วการ์ดพาทำโชว์รายการทุกหลัง: ชื่อ·ทรง · พื้นที่ผัง · ลบ · ความสูงอาคาร (`setRoofEave`) · ความชัน (`setRoofPitch`) — ครึ่งวงกลมเป็นความสูงโค้ง + กลับทิศโค้ง · ปุ่ม "เพิ่มหลังคาอีกหลัง" (`addRoof`) · "ดูทรงใน 3D" ⇄ "กลับไปผัง 2D" · **แผงขวาขั้นนี้มีแค่การ์ดพาทำ** (`cardRoof` = null)
- **ขั้น 4 มีหลังคาแล้ววาดเพิ่มไม่ได้จนกว่าจะกด "เพิ่มหลังคาอีกหลัง"** (`roofLock` = เครื่องมือ roof + ไม่ `roofArm` + ไม่มี draw → แตะผัง = เลือก/ลากหลังคาเดิม ลากที่ว่าง = เลื่อนภาพ) · เลือกทรงในป๊อปแล้ว `roofArm` = true วาดได้หนึ่งหลัง เสร็จแล้วล็อกอีก · ป๊อปหาขอบ "เพิ่มหลังคาแล้ว N หลัง" ต้องกด "เพิ่มอีกหลัง (ทรงเดิม)" ก่อนแตะหลังถัดไป
- รายการหลังคาในขั้น 4 แต่ละหลังมี **กว้าง/ยาว** (`roofDims`: จั่ว ridge/span · ครึ่งวงกลม ridge/span · rect w/d · ทรงอิสระ 4 มุมยืดตามแนวขอบรอบจุดกลาง เพิงคิด `ph` ใหม่) · **จั่ว** บอกแนวสัน + ปุ่ม "สลับแนวสัน" (`flipRidge` สลับ ridge/span + az 90°) · **ปั้นหยา** ช่องผูกกับแนวทิศ "ด้านออก–ตก / ด้านเหนือ–ใต้" (ไม่ใช่ w/d) สันอยู่ด้านยาวเสมอ ยาวสัน = ด้านยาว − ด้านสั้น — ด้านสั้นยาวเกินเมื่อไรสลับ w/d + az 90° เอง ไม่มีปุ่มสลับ · **เพิง** ดรอปดาวน์ "ลาดลงทิศ · ขอบ X ม." (`setEave`) + ปุ่ม "แตะบนผัง" (`eavePick`) · **ครึ่งวงกลม** ปุ่มความสูงโค้งด่วน + "กลับทิศโค้ง" บอกแนวแกนยาว · ก่อนขั้นวางแผง (`noPanUI`) แผงขวาไม่มีการ์ดรุ่นแผงและรายการหลังคา
- **ทรงหลายช่วง** (`P3S_MULTI`): **จั่วหลายช่วง (mgable)** · **ฟันเลื่อย (saw)** = ลากกรอบเดียวทั้งอาคาร แล้ว `p3sMultiRoof` แบ่งตามด้านสั้นเป็น N ช่วง (2–20 เลือกในป๊อป `roofOpt.spans` เริ่ม 3) เป็นจั่ว/เพิงธรรมดาหลายหลังผูก `grp` เดียว (+ `p3sMulti`) — เอนจิน/BOQ/แบบเก่าไม่ต้องรู้จัก · ฟันเลื่อยลาดลงขอบยาวที่หันใต้สุด ชัน 20° · ผนังของหลังคาที่มี grp ไม่ร่น · ทรงพื้นฐานสร้างด้วย `p3sRoofFromRect` (ระดับโมดูล) · **ทรงใหม่ให้ประกอบจากทรงพื้นฐานแบบนี้**
- **ทรงประกอบเพิ่ม** (ป๊อปเลือกทรง 15 ทรง · แถบทรงบนผัง/ป๊อปหาขอบใช้แค่ `P3S_KINDS_BASE`): กลุ่ม `grp` ใน `p3sMultiRoof` — **จั่วยกสัน** (monitor: จั่ว 20° + จั่วเล็กกว้าง 22% ยก 0.9 ม.) · **มนิลา** (ปั้นหยา 30° + จั่วกว้างครึ่งหนึ่งบนยอด) · **จั่วตัว L/T** (จั่วหลักชิดด้านเหนือ กว้าง min(45% ด้านสั้น, 40% ด้านยาว) + ปีกตั้งฉากถึงขอบใต้ ที่ปลาย/กลาง ชัน 25° สันสูงเท่ากัน) · ถามจำนวนช่วงเฉพาะ `P3S_SPANS` (mgable/saw) · หลังเดียวใน `p3sRoofFromRect`: **ดาดฟ้ามีขอบกันตก** (flat + `p3sParapet` สูง ม. แก้ได้ในรายการขั้น 4 · margin 0.8 · 3D พื้นคอนกรีต+ขอบหนา 20 ซม. ไม่มีแผ่นปิดขอบ) · **โรงจอดรถ** (เพิง 5° ชายคา 2.6 · `p3sOpen` 3D เป็นเสา ≤ 6 ม.+คาน ไม่มีผนัง) · **บนพื้นดิน** (flat ph 0.05 · `p3sGround` ขาตั้ง tilt 15 · 3D พื้นกรวด ไม่มีผนัง/แผ่นปิดขอบ) · ทุกหลังติด `p3sKind` ใช้เป็นชื่อทรงในรายการ
- **ก๊อกน้ำตัดแผง**: ก๊อกสูง ~20 ซม. เกินช่องใต้แผง → `p3sSyncObs` เขียนกรอบ ±`P3S_TAP_KEEP` 25 ซม. รอบก๊อกลง `roof.obs` (id `ท่อ@k`) เอนจินตัดแผงที่ทับออก — นับแผง/BOQ ตรง · ตัวท่อยังไม่ตัดแผง
- ป๊อปเลือกทรงมี**รูปตัวอย่าง 3D** ทุกทรง (`p3sKindPreview`/`P3SKindPic` เรนเดอร์ครั้งเดียวด้วยตัวเรนเดอร์เดียวกับป๊อปสิ่งบดบัง) · ทรงหลายช่วงกดแล้วเลือกจำนวนช่วงก่อนกด "เริ่มวาด"
