# ฝ่ายขาย — ลูกค้าสำรวจ (`surveyLeads`)

ตัวเก็บ: `useSurveyLeadStore` (`dashboard/survey-sched.jsx`) · ใบลูกค้า `LeadDrawer`/`LeadDetail` (`views-survey.jsx`) · บอร์ดงานขาย `SalesBoardView` (`sales.jsx`) · ช่วงฝ่ายขายบนบอร์ดงานติดตั้ง `FlowBoardView` (`views-flow.jsx`)

## ถังขยะลูกค้า (ผู้ใช้สั่ง ต.ค. 2026: "ไม่ลบ แต่ย้ายไปถังขยะ")
- ปุ่ม "ลงถังขยะ" ในใบลูกค้า = `leadStore.remove(id, ชื่อคนกด)` ติดธง `deleted/deletedAt/deletedBy` — **ไม่ลบจากฐาน** แบบสำรวจ/รูป/ใบเสนอราคายังอยู่
- `leadStore.leads` กรองรายที่ `deleted` ออกแล้ว ทุกหน้าจอจึงไม่เห็น · id ในถังขยะอยู่ใน `leadStore.hidden` → ใบเสนอราคา/นัดของรายนั้นหายตามจนกว่าจะกู้คืน
- หัวช่วงฝ่ายขายของบอร์ดงานติดตั้งเป็น**แคปซูลเดียว** `FlSalesDock` (`views-flow.jsx` · CSS `.fl-dock` ใน index.html): ลูกค้าใหม่ · รูปสรุปแพ็คเกจ (แอดมิน) · ถังขยะ — ต้นแบบจากวิดีโอที่ผู้ใช้ส่ง: กดถังขยะแล้วตัวแคปซูลยืดเป็นแผงรายชื่อ (กู้คืนได้ในแผง) ปุ่มอื่นหดเหลือไอคอน ปิดด้วยคลิกนอก/Esc · ลบถาวรไม่ทำในแผง ปุ่ม "เปิดทั้งหมด / ลบถาวร" ไป `TrashModal`
- หน้างานขาย (`SalesBoardView`) ยังเป็นปุ่ม "ถังขยะ" ธรรมดาที่เปิด `TrashModal` (ตัวเดียวกับถังขยะงาน `app.jsx` title/noun ต่างกัน)
- กู้คืน = ทุกคนที่มีสิทธิ์ `leads` · ลบถาวร (`leadStore.purge` ลบ `surveyLeads/<id>` + `surveyPhotos/<id>`) = แอดมิน + ใส่รหัสผ่านซ้ำ
- **ลากการ์ดลูกค้าไปวางที่ปุ่มถังขยะ** (บอร์ดงานติดตั้ง ช่วงฝ่ายขาย) ก็ทิ้งได้ (ผู้ใช้สั่ง ต.ค. 2026): ระหว่างลากภาพติดเมาส์เป็นการ์ดย่อ (`.fl-ghost`) · ปุ่มขอบประแดงรอรับ · ชี้ = แดงเต็ม ขยาย ฝาโยก ใบเดิมย่อลง (`data-drag="trash"`) · ปล่อย = สำเนาการ์ดบินโค้งย่อตัวเข้าปุ่มถังขยะ (WAAPI ใน `dropTrash`) ใบเดิมยุบความสูงตาม → ย้ายลงถัง + แถบ "เลิกทำ" 6 วินาที · ไม่ถามยืนยันเพราะกู้คืนได้ · CSS อยู่ใน index.html · ใบงานรออนุมัติในคอลัมน์ต่อรองทิ้งแบบนี้ไม่ได้
- **ความลื่น (ผู้ใช้: "กดปุ้บมาปั้บเกินไป")** — แคปซูลยืด/หดด้วย clip-path (ไม่ animate width/height · ไม่มี backdrop-filter ระหว่างยืด) เงาอยู่ที่ตัวกันที่ด้วย `filter:drop-shadow` เพราะ clip-path ตัด box-shadow · เปิดใบงาน (`DetailDrawer`) เลื่อนเข้า .56s · ใบลูกค้า `.pg-bd-in`/`.pg-sheet-in` · หยิบการ์ดย่อ .97
- **เม็ดไฮไลต์ตามเมาส์แบบหยดน้ำ** `.fl-hi` (ผู้ใช้ส่งวิดีโอต้นแบบที่ 2 + "คล้ายหยดน้ำวิ่ง สีดำไปไหม"): สีเขียวอ่อน `--primary-soft` มีประกายบน+เงา ตัวหนังสือบนเม็ด `--primary-dark` · ขยับด้วย**สปริงใน JS** (rAF เขียน style ตรง) ไม่ใช่ CSS transition — ผู้ใช้บอก transition "Movement ยังแปลกๆ" (เปลี่ยนเป้ากลางทางแล้วกระตุก) · ขอบด้านที่วิ่งไปสปริงแข็ง ขอบหลังสปริงอ่อน ยิ่งยืดยิ่งบาง (scaleY) · ออกจากแคปซูล = ค้างที่ถังขยะถ้าแผงเปิด ไม่งั้นจางหาย · โผล่ครั้งแรกวางตรงปุ่มเลย
- **เปิดใบลูกค้า = การ์ดขยายเป็นใบ / ปิด = หดกลับเข้าการ์ด** (`dashboard/pg-motion.js` · ผู้ใช้: "เวลาเปิดงานยังดูธรรมดาไป" + วิดีโอต้นแบบการ์ดขยายในที่): ใช้ตัวใบจริงตั้งแต่เฟรมแรก ย่อทั้งใบ (scale) ให้กว้างเท่าการ์ดวางทับการ์ด + clip-path ตัดส่วนที่ยาวเกิน แล้วขยายเข้าที่ (ผู้ใช้ขอให้หน้าต่างย่อ/ขยายตาม ไม่ใช่แค่กรอบเปิด) — **ห้ามทำแบบแผ่นเปล่ายืดแล้วค่อยจางเป็นใบ** (ทำรอบแรกแล้วผู้ใช้บอกแปลก) · ปิดด้วย × / Esc / พื้นหลัง = สำเนาใบหดกลับ (ctx.onClose หลังทิ้งลงถังไม่หด) · ไม่ได้เปิดจากการ์ด = ท่าเข้าเดิม `.pg-sheet-in`
- **ใบงานติดตั้ง (DetailDrawer) ยังเลื่อนเข้าจากขวา** — ลองใช้การ์ดขยายแล้ว ผู้ใช้บอกเลื่อนจากด้านข้างดีกว่า
- ที่อ่าน `surveyLeads` ตรงจาก FBDB (ไม่ผ่านตัวเก็บ) จะยังเห็นรายในถังขยะ — ของใหม่ให้อ่านผ่านตัวเก็บ
