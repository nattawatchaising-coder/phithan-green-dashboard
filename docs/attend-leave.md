# ลงเวลา · OT · การลา

> แยกมาจาก CLAUDE.md · แก้/เพิ่มข้อตกลงของเรื่องนี้ที่ไฟล์นี้

## ลงเวลา · OT ข้ามเที่ยงคืน
- **กะข้ามคืน** (`tmCarryOver` attend.jsx): ก่อน 06:00 (`TM_NIGHT_CUT`) ถ้าวันนี้ยังไม่ลงเวลาเข้า แต่ใบเมื่อวานยังเปิด (หรือปิดหลังเที่ยงคืน) = ยังเป็นวันทำงานของเมื่อวาน — `useAttend().today` และ `punch` ใช้ใบเมื่อวาน (ทำ OT 22:00–02:00 กดออกตีสองได้ · ขอ OT ลงวันที่เมื่อวาน) · หลัง 06:00 ไม่โยง (= ลืมกดออก)
- `pgTimeFix(t, min, max)` ช่วงข้ามคืน (max < min เช่น 08:30–02:00) ไม่บีบค่าที่อยู่ในช่วง — เดิมทุกค่ากลายเป็น max

## การลา (`dashboard/leave.jsx` ตรรกะ · `views-leave.jsx` เว็บ · `liff-leave.jsx` ไลน์ · prefix `lv`/`Lv`/`LnLv`)
- ข้อมูล: `config/leaveTypes` ประเภท [{key, th, days ยอด/ปี (null = ไม่จำกัด), color, adv ต้องยื่นล่วงหน้ากี่วัน, back ยื่นย้อนหลังได้}] (ไม่ผ่าน TM_ROOT) · `leaveQuota/{userId}/{ปี}/{type}` ยอดเฉพาะคน (ไม่มี = ยอดตั้งต้นของประเภท · "inf" = ไม่จำกัด) · `tmLeave/{id}` ใบลา {no LV-6910-01, userId, type, from, to, part full/am/pm, days, reason, approverId, status …}
- สถานะ/เดินสถานะใช้ชุดเดียวกับใบ OT (`tmOtMove`/`TM_OT_STATUS`) · นับวันเฉพาะวันทำงาน (`tmIsWorkday`) ครึ่งวันได้เฉพาะลาวันเดียว · ใบนับเข้าปีของวันเริ่มลา · คงเหลือ = ยอด − อนุมัติ − รออนุมัติ · ส่งเกินยอดไม่ได้
- **ต้องลาล่วงหน้า** (ผู้ใช้ขอ): `lvSendWhy` กันส่งเมื่อวันเริ่มลาห่างจากวันนี้ < `adv` วัน · ย้อนหลังได้เฉพาะ `back` · ค่าเริ่ม ลาป่วย 0 + ย้อนหลังได้ · ลากิจ 3 · พักร้อน 7 · ลาคลอด 30 · ไม่รับค่าจ้าง 3 — แก้ได้ในแท็บ "ประเภทการลา" (ค่าตั้งเก่าที่ไม่มี adv ใช้ค่าเริ่มตามคีย์ `LV_ADV_DEF`)
- สิทธิ์ `leave` (ทุกตำแหน่งที่มี ot) · `leaveApprove` (admin/lead/hr — สำเนาใน api/line/push.mjs ด้วย) · แก้ยอดรายคน = attendAll + leaveApprove · แก้ประเภท = manageUsers
- เว็บ: แท็บ "การลา" ในหน้าเวลาทำงาน (ยอดของฉัน · ใบของฉัน · รอฉันอนุมัติ · ทั้งหมด · ยอดวันลาทุกคน · ประเภท) · แผ่นเวลารายวันโชว์คนที่ลา (อนุมัติแล้ว) แยกจาก "ยังไม่ได้ลงเวลา"
- ไลน์: แท็บเวลา → หัวข้อ "การลา" (ยื่นแล้วส่งเลย ไม่มีร่าง · ยกเลิกเองได้จนกว่าจะตัดสิน) · ใบลารออนุมัติอยู่ในหัวข้อ "รออนุมัติ" ร่วมกับใบ OT · ลิงก์ `?tab=leave` = ปุ่ม "ขอลา" ช่องที่ 3 ของเมนูล่างหน้า 2 (แทนปุ่มแจ้งเตือนเดิม · `tools/richmenu.mjs` รูป `richmenu-p2.png`)
- **ยื่นใบลาได้ทางไลน์อย่างเดียว** (ผู้ใช้ขอ): เว็บไม่มีปุ่มขอลา/แก้ใบ/ส่ง/ตีกลับ — ดู อนุมัติ ไม่อนุมัติ ยกเลิก แก้ยอด · **ต้องเลือกผู้อนุมัติเสมอ** (`lvSendWhy` · ไม่มีตัวเลือก "ใครก็ได้") · ชิปประเภทในฟอร์มไลน์แถวเดียว ไม่ตกบรรทัด
- **เมนูล่าง LINE OA**: รูปวาดจาก `tools/richmenu-image.html` (canvas · สี/ฟอนต์จาก tokens.css ธีมปกติ ให้ตรงกับเว็บ · เปิดที่ localhost:8765/tools/richmenu-image.html แล้วกดดาวน์โหลด) → `tools/richmenu-p1/p2.png` → `node tools/richmenu.mjs` (token จาก env เท่านั้น ผู้ใช้รันเอง · ค่าใน PowerShell ต้องครอบ "...") · richmenu-image.py เลิกใช้แล้ว
- แจ้งเตือนชนิด `leave` (🌴) — config/linePush ที่ยังไม่มีคีย์ leave ตามสวิตช์ ot (push.mjs + views-line.jsx)
- **cron 18:00 เตือนลืมลงเวลาออก** `api/cron/clockout.mjs` (vercel.json `0 11 * * *` UTC · แผน Hobby ยิงภายในชั่วโมงนั้น) · คนที่เข้าแล้วยังไม่ออกได้การ์ดคนละใบ · เนื้อการ์ดมีบรรทัดเดียว "วันนี้ยังไม่ได้ลงเวลาออกงาน (เข้างาน HH:MM)" (ผู้ใช้สั่ง 2026-10-10 ห้ามเติมคำแนะนำ) · สวิตช์ kinds.attend · กันซ้ำ `cronRun/clockout-{วันที่}` · สรุป 20:30 (daily.mjs) ไม่มีบรรทัดลืมออกแล้ว เพิ่มใบลาที่รอคนนั้นอนุมัติแทน
