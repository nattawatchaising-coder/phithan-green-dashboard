# รูปแพ็คเกจขาย (`dashboard/pkgposter.jsx` prefix `pk`/`Pk` · โหลดก่อน views-survey.js)

> แยกมาจาก CLAUDE.md · แก้/เพิ่มข้อตกลงของเรื่องนี้ที่ไฟล์นี้

- ปุ่ม **"รูปแพ็คเกจ"** (ไอคอนเส้น image · ทรงเม็ดยาสูง 32 เท่าปุ่มปิด — ผู้ใช้ไม่เอาอีโมจิ) บนหัวใบลูกค้า (LeadDrawer · โชว์เมื่อ boq มี panelModel) → `PkPosterModal` วาด canvas 1080×1350 ดาวน์โหลด PNG · ไม่เขียนข้อมูลอะไรเลย
- สเปคจาก `lead.boq` (panels · panelModel · inverterModel/invCount · inv2 · phase · batteryKwh) · **ราคา = `lead.expValue` (มูลค่าที่คาด) ว่าง = `boq.pricing.sell`** · ช่อง **ส่วนลด** (ไม่บันทึก) = ราคาเต็มขีดฆ่า (ราคา + ส่วนลด) + ป้ายแดง "ลด ฿…"
- **หน้าตาชุดใหม่ (ต.ค. 2026 — ผู้ใช้ให้ตัวอย่างโพสต์ FOX Avocado / LIB HomeStack)**: พื้นรูปบ้านสว่าง ฝั่งซ้ายไล่ขาวให้ตัวหนังสือเข้ม · หัวซ้าย = โลโก้บริษัท ขวา = โลโก้ยี่ห้อแผง | อินเวอร์เตอร์ คั่นเส้นตั้ง · ป้ายหัวข้อกล่องกรม + เส้นยาวต่อท้าย · kWp ตัวใหญ่ · **ราคา "xxx,000.-" ตัวใหญ่สีเขียวเข้ม** + เม็ดยาใต้ราคา ("รวมติดตั้ง · ยังไม่รวม VAT 7%" / สวิตช์ **บวก VAT 7%** = ×1.07 ปัดขึ้นหลักร้อย ป้ายเป็น "รวม VAT และติดตั้ง") · รูปสินค้าลอยฝั่งขวา (แผงหลัง อินเวอร์เตอร์หน้า) · การ์ดสเปค/ผลตอบแทนเป็นกระจกขาว · **แถบล่างสีเข้ม** แท็บ "รับประกัน · บริการ" + ไอคอนวงกลม ≤ 6 ข้อ (`pkIcon` เลือกจากคำ) ข้อความตัดคำไทยด้วย `Intl.Segmenter` ตัวเลขติดหน่วย · `pkTrim` ทำพื้นขาวโปร่งเฉพาะที่ต่อกับขอบรูป (flood fill — อินเวอร์เตอร์สีขาวเคยโปร่งเป็นผี)
- **รูปสรุปแพ็คเกจ** (`pkDrawSum`): ปุ่ม "รูปสรุปแพ็คเกจ" บนหัวช่วงฝ่ายขายของบอร์ด (`views-flow.jsx` FlGroup prop `extra`) → `PkPosterModal leads=…` · ตัวเลือก = ลูกค้าที่ BOQ ครบ เรียง kWp → เฟส · ค่าเริ่ม = ลูกค้าที่ชื่อมีรุ่นอินเวอร์เตอร์ของ BOQ (ลูกค้าแพ็คเกจ เช่น "TEST Huawei SUN2000-5K-LB0") · เลือกได้ ≤ PK_SUM_MAX (8) จำ id ใน `localStorage.pk_sum_sel` · ต่อแถว: ส่วนลด (ราคาเต็มขีดฆ่า ราคาสีแดง) · ติ๊ก "แนะนำ" (แถวไฮไลต์ + ป้าย) — ไม่บันทึก · ตาราง: ขนาด+ชิปเฟส | แผง W × n / อินเวอร์เตอร์ kW | ประหยัด/เดือน | ราคา · ยี่ห้อขึ้นหัวรูปเฉพาะเมื่อทุกแถวยี่ห้อเดียวกัน
- (แบบเดิมก่อนชุดใหม่) การ์ดสินค้า: บนพื้นรูปไม่มีกรอบ/วงกลม — ซ้ายล่าง = กำลัง (650 W · 3 kW) ตัวเลขใหญ่สีเขียว + หน่วยเล็ก · ขวาล่าง = จำนวน "×n" ตัวเลขใหญ่สีกรม + "แผ่น"/"เครื่อง" (ผู้ใช้เลือก ต.ค. 2026)
- รูปสินค้า `stockImg/{id}` → `cat_panel`/`cat_inverter` · โลโก้ยี่ห้อ `cat_brand_<ยี่ห้อ>` → รูปหมวดย่อยที่เป็นยี่ห้อ (`cat_`+item.cat เช่น LONGI = sub6 · HUAWEI = sub20) → ตัวหนังสือ · ตัดพื้นขาวออก (`pkTrim`) · โลโก้วางกลางเหนือรูปสินค้า **ไม่มีกล่อง/พื้นขาวรอง** (ผู้ใช้: กล่องดูไม่เนียน)
- **ข้อมูลบริษัท · ติดต่อ** แก้ในป๊อป (ชื่อ — `+` เป็นสีเขียว · บรรทัดรอง · รูปโลโก้อัปโหลดย่อ ≤ 240 px · เบอร์ · LINE · เว็บ) กด **บันทึก** → RTDB `config/pkPosterCo` ใช้ร่วมทุกเครื่อง · ไม่มี = `BRANDING` · ส่วนลด = สติกเกอร์ดาวแฉกแดง "ลดทันที" มุมขวาบนแถบราคา
- สวิตช์ โลโก้บริษัท · ข้อมูลติดต่อ (ค่าเริ่มปิด) · แสดงราคา — จำที่ `localStorage.pk_poster_opt` · หัวข้อ/จุดเด่นแก้ได้ กดบันทึก → `config/pkPosterText` {title, wty} ใช้กับทุกลูกค้า (ยังไม่เคยบันทึก = warranties ของใบเสนอราคา → `PK_WTY_DEF`)
- พื้นหลังส่วนบน = `dashboard/assets/pkg-house-light.jpg` (บ้านสว่าง ฝั่งซ้ายฟ้าโล่ง 825×1024 ผู้ใช้ให้มา ต.ค. 2026 · รูปรายอันวางชิดบนสูง 1060 หลังคาติดแผงโผล่ใต้รูปสินค้า · เดิม `pkg-house.jpg` ยังเก็บไว้) ไล่ขาวฝั่งซ้ายที่มีตัวหนังสือ (ชุดใหม่ · เดิมมืดลง) · อยากเปลี่ยนรูปพื้น = แทนไฟล์นี้ (แนวตั้ง/กว้าง ≥ 1080 px ฝั่งซ้ายโล่ง) · ผลิตไฟ 1,400 หน่วย/kWp/ปี × 4.5 บาท
- **แบบที่ผู้ใช้ลองแล้วไม่เอา** (ต.ค. 2026 — อย่าเสนอกลับมา): จำนวนเป็นวงกลมเขียว ×n ("กลมแปลก ๆ") · เม็ดยาขาว "× n แผ่น" · ป้ายเขียวมุมขวาบน · ป้ายกำลัง W/kW เป็นเม็ดยาน้ำเงิน · โลโก้ยี่ห้อมีกล่อง/พื้นขาวรอง · ส่วนลดเป็นป้ายเล็ก (เปลี่ยนเป็นสติกเกอร์ดาวแฉก) · ชื่อรุ่น/ชนิดชิดขอบล่างการ์ด (ขยับขึ้นแล้ว) · ปุ่มเปิดเป็นอีโมจิ 🖼
- **รูปสินค้าประจำยี่ห้อ** `PK_BRAND_PHOTO` (ไฟล์ใน `dashboard/assets/`) มาก่อนรูปในคลัง — ตอนนี้ `huawei` → `pkg-inv-huawei.jpg` (อินเวอร์เตอร์ขาวพื้นขาว ผู้ใช้ให้มา ต.ค. 2026) ใช้กับอินเวอร์เตอร์ Huawei ทุกรุ่น · ยี่ห้ออื่นใช้รูปในคลังตามเดิม · คีย์เป็น kind:brand (inv:huawei · panel:longi → pkg-panel-longi.webp — ไม่มีไฟล์ = รูปคลัง) · ของขาว/โลโก้วาดผ่าน pkLift (เงาฟุ้ง + เงาแคบเข้มเป็นขอบ ผู้ใช้: อินเวอร์เตอร์ขาว/โลโก้ส่วนขาวกลืนพื้นฟ้า) · pkTrim flood fill เฉพาะขาว > 248 (หน้าเครื่องขาว 237–246 เคยโปร่งเป็นจุด)
- **รุ่น + ชนิดอินเวอร์เตอร์** (ผู้ใช้ ต.ค. 2026): การ์ดสเปคมีรุ่นใต้ตัวเลข (`item.model`) · การ์ดอินเวอร์เตอร์มีป้าย HYBRID (เขียว) / ON-GRID (กรม) จาก `invType` ในคลัง (ไม่รู้ = ไม่โชว์ ไม่เดา) · บรรทัดใต้ kWp = "ระบบ n เฟส · HYBRID" · ป้ายกระจกลอยใต้รูปอินเวอร์เตอร์ "รองรับแบตเตอรี่ในอนาคต" + ไอคอนแบต (Hybrid ที่ยังไม่มีแบต · ผู้ใช้ไม่เอาไว้ในบรรทัดใต้ kWp) · **เลือกแบบป้ายได้ 4 แบบ** (`pkHybBadge` · `o.hv` จำใน `pk_poster_opt.hv` · ปุ่มในป๊อปโชว์เมื่อเป็น Hybrid): A กระจกขาว (ค่าเริ่ม) · B เม็ดยาเขียวทึบ + ชิป HYBRID ทึบ · C สติกเกอร์วงกลม "พร้อมต่อแบตเตอรี่" เกยมุมเครื่อง + ชิป HYBRID เส้นขอบ · D การ์ดกรม HYBRID INVERTER/รองรับแบต · รูปสรุปต่อท้าย "· Hybrid" ในแถว · ไอคอนล้างแผง = แผงเอียง + หยดน้ำ (เช็กคำ ล้าง ก่อน แผง)
