# ฝ่ายขาย — ลูกค้าสำรวจ (`surveyLeads`)

ตัวเก็บ: `useSurveyLeadStore` (`dashboard/survey-sched.jsx`) · ใบลูกค้า `LeadDrawer`/`LeadDetail` (`views-survey.jsx`) · บอร์ดงานขาย `SalesBoardView` (`sales.jsx`) · ช่วงฝ่ายขายบนบอร์ดงานติดตั้ง `FlowBoardView` (`views-flow.jsx`)

## ถังขยะลูกค้า (ผู้ใช้สั่ง ต.ค. 2026: "ไม่ลบ แต่ย้ายไปถังขยะ")
- ปุ่ม "ลงถังขยะ" ในใบลูกค้า = `leadStore.remove(id, ชื่อคนกด)` ติดธง `deleted/deletedAt/deletedBy` — **ไม่ลบจากฐาน** แบบสำรวจ/รูป/ใบเสนอราคายังอยู่
- `leadStore.leads` กรองรายที่ `deleted` ออกแล้ว ทุกหน้าจอจึงไม่เห็น · id ในถังขยะอยู่ใน `leadStore.hidden` → ใบเสนอราคา/นัดของรายนั้นหายตามจนกว่าจะกู้คืน
- หัวช่วงฝ่ายขายของบอร์ดงานติดตั้งเป็น**แคปซูลเดียว** `FlSalesDock` (`views-flow.jsx` · CSS `.fl-dock` ใน index.html): ลูกค้าใหม่ · รูปสรุปแพ็คเกจ (แอดมิน) · ถังขยะ — ต้นแบบจากวิดีโอที่ผู้ใช้ส่ง: กดถังขยะแล้วตัวแคปซูลยืดเป็นแผงรายชื่อ (กู้คืนได้ในแผง) ปุ่มอื่นหดเหลือไอคอน ปิดด้วยคลิกนอก/Esc · ลบถาวรไม่ทำในแผง ปุ่ม "เปิดทั้งหมด / ลบถาวร" ไป `TrashModal`
- หน้างานขาย (`SalesBoardView`) ยังเป็นปุ่ม "ถังขยะ" ธรรมดาที่เปิด `TrashModal` (ตัวเดียวกับถังขยะงาน `app.jsx` title/noun ต่างกัน)
- กู้คืน = ทุกคนที่มีสิทธิ์ `leads` · ลบถาวร (`leadStore.purge` ลบ `surveyLeads/<id>` + `surveyPhotos/<id>`) = แอดมิน + ใส่รหัสผ่านซ้ำ
- **ลากการ์ดลูกค้าไปวางที่ปุ่มถังขยะ** (บอร์ดงานติดตั้ง ช่วงฝ่ายขาย) ก็ทิ้งได้ (ผู้ใช้สั่ง ต.ค. 2026): ระหว่างลากภาพติดเมาส์เป็นการ์ดย่อ (`.fl-ghost`) · ปุ่มขอบประแดงรอรับ · ชี้ = แดงเต็ม ขยาย ฝาโยก ใบเดิมย่อลง (`data-drag="trash"`) · ปล่อย = สำเนาการ์ดบินโค้งย่อตัวเข้าปุ่มถังขยะ (WAAPI ใน `dropTrash`) ใบเดิมยุบความสูงตาม → ย้ายลงถัง + แถบ "เลิกทำ" 6 วินาที · ไม่ถามยืนยันเพราะกู้คืนได้ · CSS อยู่ใน index.html · ใบงานรออนุมัติในคอลัมน์ต่อรองทิ้งแบบนี้ไม่ได้
- **ความลื่น (ผู้ใช้: "กดปุ้บมาปั้บเกินไป")** — แคปซูลยืด/หดด้วย clip-path (ไม่ animate width/height · ไม่มี backdrop-filter ระหว่างยืด) เงาอยู่ที่ตัวกันที่ด้วย `filter:drop-shadow` เพราะ clip-path ตัด box-shadow · เปิดใบงาน (`DetailDrawer`) เลื่อนเข้า .56s · ใบลูกค้า `.pg-bd-in`/`.pg-sheet-in` · หยิบการ์ดย่อ .97
- **เม็ดไฮไลต์ตามเมาส์แบบหยดน้ำ** `.fl-hi` (ผู้ใช้ส่งวิดีโอต้นแบบที่ 2 + "คล้ายหยดน้ำวิ่ง สีดำไปไหม"): สีเขียวอ่อน `--primary-soft` มีประกายบน+เงา ตัวหนังสือบนเม็ด `--primary-dark` · ขยับด้วย**สปริงใน JS** (rAF เขียน style ตรง) ไม่ใช่ CSS transition — ผู้ใช้บอก transition "Movement ยังแปลกๆ" (เปลี่ยนเป้ากลางทางแล้วกระตุก) · ขอบด้านที่วิ่งไปสปริงแข็ง ขอบหลังสปริงอ่อน ยิ่งยืดยิ่งบาง (scaleY) · ออกจากแคปซูล = ค้างที่ถังขยะถ้าแผงเปิด ไม่งั้นจางหาย · โผล่ครั้งแรกวางตรงปุ่มเลย
- **ลากจัดลำดับการ์ดลูกค้าในคอลัมน์ได้เอง** (ผู้ใช้: "เลื่อนจัดลำดับงานเองได้ไหม ทำอนิเมชั่นขยับแย่งที่ด้วย" ต.ค. 2026): เก็บเป็นฟิลด์ `boardRank` ของลูกค้า (`leadStore.rank` เขียน multi-path ทีเดียว ไม่แตะ updatedAt) · เรียงคอลัมน์ = รายที่ยังไม่เคยถูกจัด (เพิ่งเข้าคอลัมน์) อยู่บนสุดตามกฎเดิม (เลยวันติดตามก่อน → วันติดตาม) แล้วตามด้วยรายที่จัดแล้วตาม boardRank · วางแล้วจัดลำดับใหม่ทั้งคอลัมน์ปลายทาง (เขียนเฉพาะรายที่ลำดับเปลี่ยน) · ลากข้ามคอลัมน์ก็แทรกตรงช่องที่ปล่อย · คอลัมน์ที่จัดได้มี `data-reorder` (FlCol) — **ช่วงหน้างาน/เอกสารยังเรียงตามวันติดตั้ง/สถานะ ไม่ให้จัดเอง** (ตารางงานผูกกับวันติดตั้ง) · การ์ดหลบให้ที่ด้วยสปริง rAF (CSS transition เริ่มใหม่ทุกครั้งที่ช่องย้าย ผู้ใช้ขอให้นุ่มกว่านี้) · วางแล้ว FLIP จากตำแหน่งที่หลบไว้เข้าที่ใหม่ (MutationObserver จับตอน React ย้ายการ์ด) · `.bd-col>.bd` มี `scrollbar-gutter:stable` ให้การ์ดกว้างเท่ากันทุกคอลัมน์ (คอลัมน์ที่ล้นมีแถบเลื่อน การ์ดแคบกว่า ชื่อตัดบรรทัดต่างกัน ย้ายแล้วตัวหนังสือขยับ — ผู้ใช้ทัก) · สีเข้มขึ้นตอนชี้การ์ด (.bd-card) เป็นผ้าคลุม ::after จางเข้า ไม่ใช่สลับ background-image (CSS ไล่ค่าไม่ได้ เข้มพรวด ผู้ใช้บอกเหมือนกระตุก โดยเฉพาะตอนวางการ์ดแล้วเมาส์ค้างบนใบ)
- **ลากการ์ดบนบอร์ด = การ์ดลอยตามเมาส์** (`pgDragLift` ใน `dashboard/pg-motion.js` · ผู้ใช้: "ทำอนิเมชั่น ลากย้าย กดวางลงด้วยสิ"): ภาพลากของเบราว์เซอร์ซ่อนไว้ (รูปใส) วาดสำเนาการ์ดลอยเอง หยิบ = ย่อ 72% รอบจุดที่จับด้วยสปริง · ลาก = เอียงตามความเร็ว · วางลงคอลัมน์ = บินลงทับการ์ดที่ไปโผล่ใหม่ (ปรับกว้างเท่าการ์ดปลายทางก่อนบิน ไม่งั้นชื่อตัดบรรทัดต่างกันแล้วตัวหนังสือกระโดด — ผู้ใช้ถามว่าทำไมตัวหนังสือขยับ) + การ์ดหน้าตาใหม่ (สีขั้นใหม่) จางขึ้นทับระหว่างบิน (ผู้ใช้: "ไม่มีตอนเปลี่ยนสี") · ย้ายไม่ได้/ยกเลิก/รอยืนยัน = บินกลับที่เดิม · ทิ้งลงถัง = ตัวที่ลอยบินเข้าถัง (`pgDragTrash`) · การ์ดต้องมี data-lid / data-jid
- **จังหวะลาก/วางที่ผู้ใช้ติไว้ (ต.ค. 2026)** — ห้ามถอยกลับ: (1) **บินลงเดินด้วย rAF เล็งเป้าใหม่ทุกเฟรม** ไม่ใช่ WAAPI เป้าตายตัว — วางปุ๊บออกบินไปช่องว่างที่การ์ดอื่นหลบไว้ทันที ไม่รอข้อมูล React ย้ายการ์ดแล้วค่อยเล็งการ์ดจริง ("พึ่งวางแล้วเริ่มเลื่อน ใบงานค้างแล้วกระตุก") · วางที่เดิม/รอยืนยันปิดการขาย = pgDragSettle แค่เปลี่ยนเป้ากลับที่เดิม บินรอบเดียว (เดิมเด้งสองรอบ) (2) FLIP หลัง React ย้ายของ**คงความเร็วสปริงเดิม** และทำซ้ำได้ทุกรอบที่ React วาดใหม่ (3) **เลื่อนคอลัมน์เองตอนลากเข้าใกล้ขอบ** (โซน ≤90px เร่ง/ผ่อนนุ่ม) แทนการเลื่อนอัตโนมัติของเบราว์เซอร์ที่เร็วและกระโดด · สปริงหลบให้ที่ K150/C24 (4) ระหว่างลาก **ทั้งหน้า preventDefault dragover และ dragenter** (dragenter ไม่รับ = แดงแว้บทุกครั้งที่ข้ามขอบธาตุ) กันเคอร์เซอร์กากบาทแดงกระพริบ — เลยต้องเช็ก ok/canTrash เองใน onDrop ของคอลัมน์และถัง (5) dragleave ของคอลัมน์ล้างกรอบสีเฉพาะตอนออกนอกคอลัมน์จริง (relatedTarget) กันกรอบกระพริบ (6) ลากใบใหม่ระหว่างใบก่อนยังบิน = เลิกเฝ้า MutationObserver รอบก่อน + เก็บสำเนา [data-pgfly] ที่ค้างทิ้ง (7) ระหว่างบินลง **ออกตัวใหม่เฉพาะตอนเปลี่ยนชนิดเป้า** (ช่องว่าง/การ์ดจริง/ที่เดิม) เป้าขยับเพราะเลื่อนจอให้ตามไปเฉย ๆ — เดิมวางแล้วหมุนลูกกลิ้งทันที บินไม่จบ สำเนาค้างจอ · บินเกิน 2.5 วิ = จบเลย (8) dragend ไม่มาถึง (ปล่อยนอกหน้า/การ์ดต้นทางถูกวาดใหม่) — มี mousemove/pointerdown = การลากจบแล้ว บินกลับที่เดิม (9) **เลื่อนจอ/คอลัมน์ระหว่างบินลง (wheel/scroll) = เลิกบินทันที** เผยการ์ดจริง สำเนาจาง 150ms — สำเนาลอยบน body ไม่ถูกคอลัมน์ตัดขอบ ถ้าไล่ตามจะลอยพ้นคอลัมน์ขึ้นไปทับหัวหน้า
- **บอร์ดงานขาย (SalesBoardView) และบอร์ดขออนุญาต (PermitQueueView) ใช้ระบบลากเดียวกัน (ต.ค. 2026)** — เปลือกคอลัมน์ต้องเป็น `FlCol` (views-flow.jsx) เท่านั้น เพราะ pg-motion.js อ่านคลาส .bd-col/.bd · ลากเริ่มที่ pgDragLift · วางสำเร็จ = pgDragDrop ก่อนบันทึก · วางที่เดิม/ต้องถามยืนยัน/ตีกลับ = pgDragSettle · วางที่ห้าม = ไม่ต้องทำอะไร (บินกลับเอง) · onDrop ต้องเช็ก ok เอง และ dragleave เช็ก relatedTarget · กล่องเลื่อนแนวนอนใส่ className="fl-board" + onDragEnd ล้างสถานะ (ผู้ใช้สั่ง: เอาลูกเล่นลากไปใช้บอร์ดอื่น)
- **ลากสลับลำดับรายการในใบเสนอราคา (ต.ค. 2026)** — ปุ่มจับ ⋮⋮ (.row-grip) หน้าชื่อรายการ → `window.pgRowDrag(e, แถว, moveItem)` (pg-motion.js · pointer events ไม่ใช่ลากของเบราว์เซอร์ เพราะแถวมีช่องกรอก) · แถวต้องมี data-row และ **key คงที่** (QuoteEditor เติม id ให้รายการเก่าที่ไม่มีตอนเปิดใบ) ไม่งั้น React ไม่ย้ายโหนด FLIP จับไม่ได้ · สลับเมื่อจุดกลางแถวที่ลากเลยจุดกลางแถวข้างเคียง · Esc/ปล่อยที่เดิม = ไม่เปลี่ยน · ลำดับ = ลำดับในใบที่ออก (ดึงราคา BOQ/แบบ 3D ยังเขียนลงรายการแรก) · **BOQ ไม่ทำ** — สายไฟผูกกับลำดับแถว (ผลคำนวณขนาดสาย/รางไฟ/อินเวอร์เตอร์อ้างตามตำแหน่ง) สลับแล้วเสี่ยงคิดผิด
- **เปิดใบลูกค้า = การ์ดขยายเป็นใบ / ปิด = หดกลับเข้าการ์ด** (`dashboard/pg-motion.js` · ผู้ใช้: "เวลาเปิดงานยังดูธรรมดาไป" + วิดีโอต้นแบบการ์ดขยายในที่): ใช้ตัวใบจริงตั้งแต่เฟรมแรก ย่อทั้งใบ (scale) ให้กว้างเท่าการ์ดวางทับการ์ด + clip-path ตัดส่วนที่ยาวเกิน แล้วขยายเข้าที่ (ผู้ใช้ขอให้หน้าต่างย่อ/ขยายตาม ไม่ใช่แค่กรอบเปิด) · **ท่าเบลอชัด** — ผู้ใช้เลือกจาก 4 ท่าที่ทำให้ลอง (โค้ง/สปริง/เปิดประตู/เบลอชัด): พุ่งเส้นตรง เริ่มจางเบลอ 10px แล้วคมชัดขึ้นระหว่างขยาย (คีย์เฟรมถี่คำนวณเอง) · ปิด = ท่าเดิมย้อนกลับ · **การ์ดต้นทางหายไปตลอดที่ใบเปิด** (ผู้ใช้: "เปิดมาแล้วให้หายไปก่อน ปิดค่อยกลับไปที่เดิม") ใบหดกลับไปเติมที่ว่าง · clip-path ขยายเลยขอบใบออกไปจนพ้นเงาระหว่างขยาย (ถ้าค้างกรอบพอดีใบ จบท่าแล้วเงาโผล่พรวด — ผู้ใช้ทัก) — ปิดทางอื่น (ย้ายลงถัง ฯลฯ) มีตัวเฝ้าดูใบถูกถอดแล้วคืนการ์ด — **ห้ามทำแบบแผ่นเปล่ายืดแล้วค่อยจางเป็นใบ** (ทำรอบแรกแล้วผู้ใช้บอกแปลก) · ปิดด้วย × / Esc / พื้นหลัง = สำเนาใบหดกลับ (ctx.onClose หลังทิ้งลงถังไม่หด) · ไม่ได้เปิดจากการ์ด = ท่าเข้าเดิม `.pg-sheet-in`
- **เปิดใบเสนอราคาจากแถวในใบลูกค้า = ขยายออกจากแถว / ปิดหดกลับแถว** (ผู้ใช้: "หน้าภายใน กดไปมันก็เด้งขึ้นมาปกติ") — ปุ่มที่ใส่ `data-zoom` เป็นต้นทางได้เหมือน .bd-card (แถวใบ + ปุ่ม "ทำใบใหม่" ใน SalesQuoteList) · QuoteEditor เรียก pgZoomFromCard/pgZoomToCard เหมือน LeadDrawer · ใบซ้อนใบได้ → pg-motion จำต้นทางไว้ที่ตัวใบแต่ละใบ (`el._pgz`) · **แผงลูกค้าบนบอร์ดไม่ปิดตอนเปิดใบเสนอราคาแล้ว** (ใบ z 118 ทับแผง 116) — เดิมปิดแผงทันที ใบขยายจากแถวที่หายไป ผู้ใช้ว่า "ดูแปลก" · ใบที่เปิดทับมี `data-layer` → Esc ของแผงข้างใต้ไม่ทำงาน
- แถวแท็บ `.ld-tabs` สูงตายตัว 44px + margin-bottom ของแท็บเลื่อนพร้อม height — เดิมสลับแท็บแล้วแถวเตี้ยลง/สูงเกินชั่ววูบ ใบใต้แท็บกระตุก (ผู้ใช้: "เวลากดแทบด้านบนไม่ต้องสั่นได้ไหม")
