# งานเฉพาะแอดมิน (adminOnly)

> แยกมาจาก CLAUDE.md · แก้/เพิ่มข้อตกลงของเรื่องนี้ที่ไฟล์นี้

- งาน/ลูกค้าที่**แอดมินสร้าง** (ตั้งแต่ ต.ค. 2026) ติด `adminOnly: true` ผ่าน `store.blank()`/`leadStore.blank()` (`pgAdminFlag` components.jsx) — **คนที่ไม่ใช่แอดมินไม่เห็น** ทั้งรายการ ถังขยะ ใบเสนอราคาและนัดของรายนั้น
- กรองที่ตัวเก็บ `useJobStore`/`useSurveyLeadStore` (`usePgAdmin` · `raw`/เลขรันยังนับจากทั้งหมด) · คืน `hidden` (Set id) ให้ app.jsx กรอง quotes/appts (`hideIds`) · ใครเป็นแอดมินมาจาก `useAuthStore` → `pgSetViewer` (ทั้งเว็บและ LIFF)
- แอดมินเห็นรูปตาปิด `<AdminOnlyMark rec>` หน้าชื่อ (การ์ดบอร์ด/ขาย/ใบอนุญาต · ตาราง · หัวใบงาน/ใบลูกค้า) · ปุ่ม `<AdminHideBtn rec path>` (เฉพาะแอดมิน) ในหัวใบงาน (แถวรหัส) และใบลูกค้า (ใต้ชื่อ): "ซ่อนอยู่ · ยกเลิกซ่อน" / "ซ่อน" = `pgSetHidden` สลับธง (ยืนยันก่อน) · ซ่อนงานเก่าเองได้ด้วยปุ่มนี้
- ที่อ่าน jobs/surveyLeads ตรงจาก FBDB (ไม่ผ่านตัวเก็บ) ไม่ถูกกรอง — ของใหม่ให้อ่านผ่านตัวเก็บ
