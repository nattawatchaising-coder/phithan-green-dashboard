## ลงเวลา · OT ข้ามเที่ยงคืน
- **กะข้ามคืน** (`tmCarryOver` attend.jsx): ก่อน 06:00 (`TM_NIGHT_CUT`) ถ้าวันนี้ยังไม่ลงเวลาเข้า แต่ใบเมื่อวานยังเปิด (หรือปิดหลังเที่ยงคืน) = ยังเป็นวันทำงานของเมื่อวาน — `useAttend().today` และ `punch` ใช้ใบเมื่อวาน (ทำ OT 22:00–02:00 กดออกตีสองได้ · ขอ OT ลงวันที่เมื่อวาน) · หลัง 06:00 ไม่โยง (= ลืมกดออก)
- `pgTimeFix(t, min, max)` ช่วงข้ามคืน (max < min เช่น 08:30–02:00) ไม่บีบค่าที่อยู่ในช่วง — เดิมทุกค่ากลายเป็น max

- **วิธีคิด OT แบบใหม่** (ผู้ใช้ 2026-10-16 "ให้กดระบุช่วงทำ OT เองเลย"): `tmOtCalc`/`tmOtFill` attend.jsx — นับตามช่วงที่ผู้ขอกรอกทั้งช่วง ไม่ตัดเวลางาน ไม่ล็อกกับเวลาลงเข้า-ออกแล้ว (ฟอร์มไลน์ `LnOtForm` ใช้ limit แค่เติมค่าเริ่ม) · ปัดลง roundMins / ขั้นต่ำ minOtMins เหมือนเดิม
  - วันหยุด: ปุ่ม "ทั้งวัน" = startEarly–end (08:30–17:30) · หักพักเฉพาะส่วนที่ทับ 12:00–13:00 แล้ว workMins (8 ชม.) แรกของเวลาทำงาน ×`otRates.holiday` (1.5) · เกินจากนั้น ×`otRates.holidayOt` (2) — ใบเก็บ `parts` [{kind, mins, rate}] ถ่ายตัวคูณติดใบ · `tmOtPayMins` ใช้ parts ก่อน ไม่มี = mins × rate (ใบเก่า)
  - ใบร่าง/รออนุมัติ คิดใหม่ตามวิธีใหม่ตอนแสดง (`useOtClaims(cfg)` + TmOtModal · ผู้ใช้สั่ง "คำนวนเวลาให้ใหม่") กดอนุมัติแล้วค่าใหม่บันทึกลงใบ · ใบที่ตัดสินแล้วไม่แตะ · ค่าเริ่ม otRates เปลี่ยนเป็น holiday 1.5 / holidayOt 2 — ค่าที่บันทึกใน config/workHours ทับค่าเริ่ม ต้องแก้ในหน้าตั้งค่าเวลาทำงาน
- **แอดมินแก้เวลา/ลงเวลาแทนคนลืมลง** (ผู้ใช้ 2026-10-16 · แก้ได้ทั้งเข้าและออก): แผ่นรายวัน ปุ่ม "แก้เวลา" ต่อแถว · "ลงเวลาแทน" ที่แถวยังไม่ได้ลง + ดรอปดาวน์เลือกคน (วันหยุด) · เฉพาะ `usePgAdmin()` · ไม่มีช่องเหตุผล (ผู้ใช้ตัดออก) · `useAttendAdmin().setTimes` ปั๊มที่แก้ติด adminFix/was/byId/byName (พิกัดเดิมคงไว้) + hist "admin-edit" · ดัชนี attendDay มี `fix` → ไม่โชว์ป้ายแล้ว (ผู้ใช้ไม่เอา) แต่ใช้ซ่อนคำเตือน "ไม่มีพิกัด" (ขึ้น — ไม่นับในสถิติ) และงานที่แจ้งว่างขึ้น "ออฟฟิศ" · ลงแทนตั้ง place office

## การลา (`dashboard/leave.jsx` ตรรกะ · `views-leave.jsx` เว็บ · `liff-leave.jsx` ไลน์ · prefix `lv`/`Lv`/`LnLv`)
- ข้อมูล: `config/leaveTypes` ประเภท [{key, th, days ยอด/ปี (null = ไม่จำกัด), color, adv ต้องยื่นล่วงหน้ากี่วัน, back ยื่นย้อนหลังได้}] (ไม่ผ่าน TM_ROOT) · `leaveQuota/{userId}/{ปี}/{type}` ยอดเฉพาะคน (ไม่มี = ยอดตั้งต้นของประเภท · "inf" = ไม่จำกัด) · `tmLeave/{id}` ใบลา {no LV-6910-01, userId, type, from, to, part full/am/pm, days, reason, approverId, status …}
- สถานะ/เดินสถานะใช้ชุดเดียวกับใบ OT (`tmOtMove`/`TM_OT_STATUS`) · นับวันเฉพาะวันทำงาน (`tmIsWorkday`) ครึ่งวันได้เฉพาะลาวันเดียว · ใบนับเข้าปีของวันเริ่มลา · คงเหลือ = ยอด − อนุมัติ − รออนุมัติ · ส่งเกินยอดไม่ได้
- **ต้องลาล่วงหน้า** (ผู้ใช้ขอ): `lvSendWhy` กันส่งเมื่อวันเริ่มลาห่างจากวันนี้ < `adv` วัน · ย้อนหลังได้เฉพาะ `back` · ค่าเริ่ม ลาป่วย 0 + ย้อนหลังได้ · ลากิจ 3 · พักร้อน 7 · ลาคลอด 30 · ไม่รับค่าจ้าง 3 — แก้ได้ในแท็บ "ประเภทการลา" (ค่าตั้งเก่าที่ไม่มี adv ใช้ค่าเริ่มตามคีย์ `LV_ADV_DEF`)
- สิทธิ์ `leave` (ทุกตำแหน่งที่มี ot) · `leaveApprove` (admin/lead/hr — สำเนาใน api/line/push.mjs ด้วย) · แก้ยอดรายคน = attendAll + leaveApprove · แก้ประเภท = manageUsers
- เว็บ: แท็บ "การลา" ในหน้าเวลาทำงาน (ยอดของฉัน · ใบของฉัน · รอฉันอนุมัติ · ทั้งหมด · ยอดวันลาทุกคน · ประเภท) · แผ่นเวลารายวันโชว์คนที่ลา (อนุมัติแล้ว) แยกจาก "ยังไม่ได้ลงเวลา"
- ไลน์: แท็บเวลา → หัวข้อ "การลา" (ยื่นแล้วส่งเลย ไม่มีร่าง · ยกเลิกเองได้จนกว่าจะตัดสิน) · ใบลารออนุมัติอยู่ในหัวข้อ "รออนุมัติ" ร่วมกับใบ OT · ลิงก์ `?tab=leave` = ปุ่ม "ขอลา" ช่องที่ 3 ของเมนูล่างหน้า 2 (แทนปุ่มแจ้งเตือนเดิม · `tools/richmenu.mjs` รูป `richmenu-p2.png`)
- **ยื่นใบลาได้ทางไลน์อย่างเดียว** (ผู้ใช้ขอ): เว็บไม่มีปุ่มขอลา/แก้ใบ/ส่ง/ตีกลับ — ดู อนุมัติ ไม่อนุมัติ ยกเลิก แก้ยอด · **ต้องเลือกผู้อนุมัติเสมอ** (`lvSendWhy` · ไม่มีตัวเลือก "ใครก็ได้") · ชิปประเภทในฟอร์มไลน์แถวเดียว ไม่ตกบรรทัด
- **เมนูล่าง LINE OA**: รูปวาดจาก `tools/richmenu-image.html` (canvas · สี/ฟอนต์จาก tokens.css ธีมปกติ ให้ตรงกับเว็บ · เปิดที่ localhost:8765/tools/richmenu-image.html แล้วกดดาวน์โหลด) → `tools/richmenu-p1/p2.png` → `node tools/richmenu.mjs` (token จาก env เท่านั้น ผู้ใช้รันเอง · ค่าใน PowerShell ต้องครอบ "...") · richmenu-image.py เลิกใช้แล้ว
- แจ้งเตือนชนิด `leave` (🌴) — config/linePush ที่ยังไม่มีคีย์ leave ตามสวิตช์ ot (push.mjs + views-line.jsx)
- **cron 17:00 เตือนลืมลงเวลาออก** (ผู้ใช้สั่ง ต.ค. 2026 เดิม 18:00) `api/cron/clockout.mjs` (vercel.json `0 10 * * *` UTC · แผน Hobby ยิงภายในชั่วโมงนั้น) · คนที่เข้าแล้วยังไม่ออกได้การ์ดคนละใบ · เนื้อการ์ดมีบรรทัดเดียว "วันนี้ยังไม่ได้ลงเวลาออกงาน (เข้างาน HH:MM)" (ผู้ใช้สั่ง 2026-10-10 ห้ามเติมคำแนะนำ) · สวิตช์ kinds.attend · กันซ้ำ `cronRun/clockout-{วันที่}` · สรุป 20:30 (daily.mjs) ไม่มีบรรทัดลืมออกแล้ว เพิ่มใบลาที่รอคนนั้นอนุมัติแทน

## รายการใบ OT (ผู้ใช้สั่ง ต.ค. 2026)
- แบ่งหัวรายเดือน (เดือน · จำนวนใบ · ชม.ที่อนุมัติแล้ว)
- ปุ่ม "ลบใบนี้": เจ้าของลบได้เฉพาะร่าง · แอดมิน (`usePgAdmin`) ลบได้ทุกสถานะ · ต้อง `askConfirm` ก่อน
- ใบสรุป OT/Excel ช่องอัตราและชม.คิดค่าแรงใช้ `parts` + `tmOtPayMins` เสมอ ห้ามคูณ mins × rate เดียว
- แอปไลน์ ดรอปดาวน์งาน (ลงเวลา/ใบ OT) มีชิป "พิมพ์เอง" (`LN_JOB_TXT` · ผู้ใช้ไม่เอาไว้ในดรอปดาวน์ ดูไม่ดี) กดแล้วช่องเลือกกลายเป็นช่องพิมพ์ — งานที่ยังไม่มีในระบบ เช่น สำรวจลูกค้าใหม่ · ข้อความเก็บลง jobCode (jobId null) เพื่อให้ทุกหน้าที่โชว์ jobCode เห็นเลย
- บัญชีระบบ ADMIN (`u-admin`) ไม่โผล่ในเรื่องลงเวลา/OT/การลา (`tmIsSysAcct`): ไม่อยู่ในรายชื่อผู้อนุมัติ OT/ลา · แถวยังไม่ลงเวลา · ดรอปดาวน์ลงเวลาแทน · สรุปรายเดือน — ตัดเฉพาะบัญชีนี้ ไม่ตัดคนจริงที่มีสิทธิ์แอดมิน (ผู้ใช้สั่ง ต.ค. 2026)

## หน้า "เวลาทำงาน" บนเว็บ — 4 แท็บ (ผู้ใช้สั่ง ต.ค. 2026: เดิม 8 แท็บ กดแล้วงง เอกสารออกหลายจุดซ้ำ · รอบ 2: "แค่ยุบรวมแต่ไม่ได้แก้หน้าตา" → ออกแบบหน้าตาใหม่ทั้งชุด)
- โค้ดหน้าตาอยู่ท้าย `views-attend.jsx` ช่วง "หน้าตาชุดใหม่" · CSS รวมใน `TM_CSS` คลาส `.tmv-*` · จอแคบใช้ `useTmNarrow` วัดความกว้างกล่องจริง (<860 ใส่คลาส `.nw`) **ไม่ใช้ @media** (มีเมนูข้างทำให้กล่องแคบกว่าจอ) และไม่ใช้ container query (กล่องจะกลายเป็นที่ยึดของ modal `position:fixed` ข้างใน)
- บนสุด `TmHero`: ไอคอนสถานะ + เวลาเข้า→ออกตัวใหญ่ + ป้ายสถานะ (ยังไม่ได้ลง/กำลังทำงาน/ออกงานแล้ว) · แถบทีมวันนี้ `TmTeamToday` (เฉพาะคนดูทุกคนได้) · ปุ่มทึบ "เปิดใบ OT" ปุ่มเดียว
- แท็บเป็น `TmSeg` (หลุม + ป้ายตัวเลข)
- **วันนี้** (`TmDaySheet`): การ์ดคน "ยังไม่ลงเวลา" (ปุ่มลงแทน) / "ลาวันนี้" + **ไทม์ไลน์** `TmTimeline` แถบเวลาแต่ละคนเทียบช่วงเวลางาน (แถบจาง) เส้นแดง = ตอนนี้ · ลายทาง = กำลังทำงาน · แดง = ลืมกดออก · แก้/ลบเป็นปุ่มไอคอนท้ายแถว · คนไม่มีสิทธิ์ดูทุกคนเห็น `TmMyDays` (ไทม์ไลน์ของตัวเองรายวัน)
- **คำขอ OT · ลา** (`TmRequests`): การ์ด `TmReqCard` (ไอคอนสี · สถานะ · รูปคน · จำนวน) แบ่งรายเดือน · ขอบเขต รอฉันอนุมัติ/ของฉัน/ทั้งหมด × ชนิด · **ปุ่ม "อนุมัติ" บนการ์ดในกล่องรออนุมัติ** ถาม `askConfirm` ก่อน (ลาโชว์คงเหลือหลังอนุมัติ) แล้วใช้ `move`/`moveLv` ตัวเดิม (แจ้งเตือนเหมือนเดิม) · กดการ์ด = เปิดใบเต็ม · "ของฉัน" โชว์วันลาคงเหลือ
- **สรุปเดือน · ออกเอกสาร** (`TmMonthAll`) = **จุดออกเอกสารจุดเดียว**: ปุ่ม "ออก Excel ทั้งเดือน" + การ์ดตัวเลขรวม (ชม.ทำงาน · OT อนุมัติ · ชม.คิดค่าแรง · รออนุมัติ · ลืมกดออก) + การ์ดรายคน: แถบสีรายวัน `TmHeat` (เขียวเข้มตามชั่วโมง · แดง = ลืมออก · ม่วง = วันหยุด · เทา = วันทำงานไม่มีใบ — ห้ามทำช่องว่างจางจนมองไม่เห็น ผู้ใช้ทักแล้ว · มีคำอธิบายสีเหนือรายชื่อ) + ตัวเลข OT + ปุ่ม "ใบ OT" (TmOtPaper) + ลูกศรกางปฏิทิน `TmDayGrid` (แอดมินกดช่องวันได้ = แก้เวลา / ลงเวลาแทนวันที่ไม่มีใบ ถึงวันนี้ — หน้าต่างเดียวกับแท็บวันนี้ `TmTimeEdit` ผู้ใช้สั่ง) · คนที่ไม่มีข้อมูลจางและอยู่ท้าย · รอบ OT = รอบที่จบในเดือนนั้น (ไม่ตั้งวันตัด = เดือนปฏิทิน)
- วันหยุด (เสาร์-อาทิตย์ตามที่ตั้ง + วันหยุดบริษัท) ต้องระบุให้เห็นทุกจุด: ป้ายม่วง `tmOffTH` "วันหยุด · วันเสาร์ / ชื่อวันหยุด" ที่หัวหน้า แถบเลือกวัน หัวการ์ดเข้า-ออกงาน หน้าว่าง และไทม์ไลน์ของฉัน — สีม่วง `--st-design` ชุดเดียวกับช่องวันหยุดในแถบสีรายวัน (ผู้ใช้สั่ง)
- **ตั้งค่า** (`TmSettings`) เวลาทำงาน·วันหยุด·อัตรา OT / ประเภทการลา / ยอดวันลารายคน
- **สาย** = เข้าหลัง startLate **และ** ทำไม่ครบ workMins (`tmIsLate` · ผู้ใช้สั่ง ต.ค. 2026 ทำครบ 8 ชม.ถือว่าปกติ) · ยังไม่กดออก = ไม่ติดธง
