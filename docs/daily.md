# รายงานประจำวันหน้างาน (`daily.jsx` `views-daily.jsx` `liff-daily.jsx`)

ข้อตกลง (ผู้ใช้สั่ง 2026-11-10):
- **เลขขั้นคิดจากตำแหน่งเสมอ** (`drRenumber`) — ลบ/เพิ่มแถวแล้วเลข 1, 1.1, 2 … เรียงใหม่เอง ห้ามพึ่งเลข `no` ที่เก็บไว้
- **ตารางขั้นงานเป็นของทั้งงาน**: `dailyPlan/{jobId}` = `{ mode, steps, updatedAt }` เขียนเมื่อแก้ตาราง/แบบฟอร์มในใบล่าสุดของงาน (ใบย้อนหลังไม่ทับ) · วันใหม่ `drBlank(..., plan)` เริ่มจากชุดนี้ ยกเว้นใบก่อนหน้าแก้ใหม่กว่า (เช่นแก้ % จาก LINE) · ใบรายวันยังเก็บสำเนาตารางของวันนั้นเป็นเอกสาร
- ปุ่ม **ย้อนกลับ** ในตาราง (เก็บในเครื่อง 50 ครั้ง ต่อใบที่เปิดอยู่) · แบบจัดเต็มขยายฟอร์มกว้างสุด 1400px ไม่ให้คอลัมน์ "ทำไปแล้ว" ตกขอบ
- ใบรายงาน/PDF มีกราฟ (`DrPaperChart`): แกนต์ แผน vs จริง (เฉพาะแถวที่มีวัน) + แถบ % รายหัวข้อ (หัวข้อที่มีขั้นย่อย = เฉลี่ยขั้นย่อย)
- **งานบ้าน: ฟอร์มรายวันกรอกแค่ "ทำไปแล้ว %"** (จัดใหม่ พ.ย. 2026 · ผู้ใช้: ข้างในยากและเยอะ) — คอลัมน์น้ำหนักงาน ถังขยะ และปุ่มคืนชุดมาตรฐาน พับไว้ใต้ปุ่ม "ปรับน้ำหนักงาน / ลบหัวข้อ" ใน `DrStepTable` (state `tune` · `showW` `canRow`) · น้ำหนักรวมไม่ครบ 100 ยังเตือนแม้พับ · แบบจัดเต็ม (โครงการ) ไม่เปลี่ยน
- **ฟอร์มรายวัน รอบ 3 (พ.ย. 2026 · ผู้ใช้: "เอาใช้งานจริง ใช้ง่าย")**: ทีมช่างดึงจากใบก่อนหน้า (`drBlank` · ฟอร์มตั้งใบเปล่าใหม่เมื่อใบก่อนหน้าโหลดตามมา — dep จำนวนวันก่อนหน้า) · แถวเลือกวันแถวเดียว (ปุ่มวันที่เปิดปฏิทินด้วย `showPicker` ช่องจริงซ่อนใต้ปุ่ม) · สวิตช์ ปกติ/จัดเต็ม ย้ายไปท้ายฟอร์ม หัวเหลือป้าย "แบบจัดเต็ม" · ลายเซ็นพับเป็นบรรทัดสรุป (ปุ่มส่ง/อนุมัติเรียกเซ็นเองอยู่แล้ว) · ลบใบอยู่ในเมนู ⋯ ยืนยันด้วย `askConfirm`
- ผู้ใช้ตอบแล้ว (พ.ย. 2026): **หัวข้อเสริมแบบจัดเต็ม (5–8) พับไว้ กดเปิดเมื่อใช้** (`DrSection fold` · ตอนพับโชว์บรรทัดสรุป) · **อากาศรวมแถวเดียว** เขียนทั้ง weatherAm/weatherPm · ปุ่ม "บ่ายต่างจากเช้า" แยกสองแถว (ใบที่บ่าย≠เช้าแยกให้เอง) · ใบพิมพ์ยังมีสองช่วง
- **ตารางขั้นงานงานโครงการ แบบ ก (พ.ย. 2026 · ผู้ใช้: ตาราง 40 แถวเป็นช่องกรอกทั้งหมด "ดูแล้วลายตามาก")** — `DrStepTable` เมื่อมีวันแผน/วันจริง:
  - โหมด **"อัปเดตวันนี้"** (ค่าเริ่มต้น): โชว์เป็นข้อความ + แถบ % พับตามหัวข้อใหญ่ (หัวข้อโชว์ช่วงวันแผน · เสร็จ/กำลังทำ/ยังไม่เริ่ม · x/y ขั้น · % = เฉลี่ยขั้นย่อย เหมือนกราฟในใบพิมพ์) · หัวข้อที่กำลังทำกางเอง (ไม่มีเลยกางหัวข้อแรกที่ยังไม่เสร็จ) · กางทั้งหมด/พับทั้งหมด · **แตะแถว = กางช่องแก้แถวนั้นแถวเดียว** (เริ่มจริง · เสร็จจริง · ปุ่ม % 0/25/50/75/100 + ช่องพิมพ์)
  - ใส่ % แล้ว **วันเริ่ม/เสร็จจริงที่ยังว่างเติมเป็นวันที่ของใบนี้ให้** (`today={date}` · >0 เติมเริ่ม · 100 เติมเสร็จ · ไม่ทับค่าที่มี · กดย้อนกลับได้)
  - โหมด **"แก้แผนงาน"**: ตารางช่องกรอกเต็มแบบเดิม (ชื่อ · วันแผน · เพิ่ม/ลบ · คืนชุดมาตรฐาน)
  - จอแคบ (≤560px) แถบ % ย้ายไปใต้ชื่อ · หัวข้อไม่ใส่พื้นสี (ธีมมืด `--primary-soft` สว่าง ตัวหนังสือหาย) · ใบที่ล็อกแล้วดูได้อย่างเดียว ไม่มีแถบโหมด
  - งานบ้าน (กรอกแค่ %) ใช้ตารางเดิม ไม่เปลี่ยน
