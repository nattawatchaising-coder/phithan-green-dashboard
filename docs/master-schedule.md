# Master Schedule งานโครงการ (`dashboard/master.jsx`)

> ผู้ใช้ขอ 13 พ.ย. 2026: "Master Schedule ของงานโครงการ มาใส่ในงานที่เป็นงานติดตั้งแล้ว" · ส่งไฟล์ตัวอย่าง `Simple-Project-Plan-Template-2026.xlsx` ให้ยึดหน้าตา

## อยู่ตรงไหน
- การ์ด **Master Schedule** ในใบงาน แท็บภาพรวม ใต้การ์ดนัดหมายและทีม — **เฉพาะ `job.type === "project"`** (`drawer.jsx` → `window.MsCard`)
  - **การ์ด = เมนูกางลงแบบการ์ดสเปกระบบ** (ผู้ใช้สั่ง 21 พ.ย. 2026): หัว "แผนงานโครงการ" บรรทัดสรุป + วง % + "ดูทั้งหมด" · กางแล้วเป็นหมวดตามหัวข้อใหญ่ (กดกางทีละหมวด) งานย่อยมีช่อง % + ปุ่มถูก (=100%) **บันทึกทันที** (`MsQuickPct` → `ms.save` ทั้งแผน เติมวันเริ่ม/เสร็จจริงเองแบบตัวแก้) · ใช้ได้เมื่อทำแผนแล้ว (`ms.rows`) และ canEdit · หมวดงานติดตั้ง (`ro`) ดูอย่างเดียว อัปเดตที่รายงานประจำวัน · ปุ่มท้าย "เปิดแผนงานเต็ม" = หน้าต่างเต็ม
  - (เดิม) การ์ด = วง % รวม + แกนต์ย่อเฉพาะหัวข้อใหญ่ · กดเปิดหน้าต่างเต็ม (`MsModal` · portal ไป body เพราะลิ้นชักมี transform · zIndex 115)
  - แก้ได้เมื่อ `!roMode && onEdit` (โหมดฝ่ายขออนุญาต/ฝ่ายขายดูอย่างเดียว)

## หน้าตา (ตามไฟล์ตัวอย่าง)
- หัวสรุป: วง % รวม · เริ่ม/จบ/รวมกี่วัน/เหลือกี่วัน (เลยกำหนด = แดง) · กล่อง งานทั้งหมด · เสร็จแล้ว · กำลังทำ · ยังไม่เริ่ม · ล่าช้า (โชว์เมื่อมี)
- ตาราง: ID (1, 1.1) · งาน + ผู้รับผิดชอบ · เริ่ม · จบ · แถบ % · ป้ายสถานะ — **แถบแกนต์เดียวต่องาน = ช่วงแผน ระบายทับตาม %** (ไม่มีแถบ "ทำจริง" แยก)
  - หัวแกนต์: เดือน · สัปดาห์ที่ (นับจากสัปดาห์ที่โครงการเริ่ม จันทร์–อาทิตย์) · วันที่ + วันในสัปดาห์ (เมื่อช่วง ≤ 7 สัปดาห์) · แรเงาวันอาทิตย์ · เส้นแดงวันนี้
  - จอ > 1180 ครบทุกคอลัมน์ · 860–1180 ตัดคอลัมน์เริ่ม/จบ · ≤ 860 เหลือ งาน + %
- สถานะคิดเอง: 100% = เสร็จแล้ว · เลยวันจบแผนและยังไม่ 100 = **ล่าช้า** · > 0 = กำลังทำ · 0 = ยังไม่เริ่ม
- % หัวข้อใหญ่ / % รวม = ถ่วงตามจำนวนวันแผนของงานย่อย
- **ดู / ออก PDF**: A3 แนวนอน (`msPrintHTML` → `SuReportView`) ชื่อไฟล์ `MS_รหัสโครงการ_ชื่อโครงการ_วัน-เดือน-ปี` (`rpFileName(job, "MS")`) · ช่วง ≤ 12 สัปดาห์ หัวรายวัน ยาวกว่านั้นหัวรายสัปดาห์ · body กว้างคงที่ 1500px

## ข้อมูล
- `masterSchedule/{jobId}` = `{ rows: [{id, th, head, owner, planStart, planEnd, pct, link}], updatedAt, byName }` · บันทึกด้วยปุ่ม "บันทึก" ทีเดียวทั้งแผน (`set`)
- ยังไม่เคยบันทึก = โชว์แม่แบบ `MS_TEMPLATE` (เริ่มโครงการ · ออกแบบ · ขออนุญาต · จัดซื้อ & ขนส่ง · งานติดตั้ง · ทดสอบ & เชื่อมต่อ · ส่งมอบงาน)
- หัวข้อ `link: "install"` (งานติดตั้ง): **งานย่อยดึงสดจากตารางขั้นงานของรายงานประจำวัน** (`useDailyReports` → `dailyPlan` หรือใบล่าสุดถ้าใหม่กว่า · หัวข้อใหญ่ของตารางขั้นงาน 1 แถว ช่วงวัน/% รวมขั้นย่อย) ไม่เก็บซ้ำ — ช่างอัปเดต % ที่รายงานประจำวันที่เดียว · ยังไม่มีตาราง = ใช้วันนัดติดตั้ง (`job.stageDates.install`) และแก้ % ในแผนนี้เองได้ · ผู้รับผิดชอบ = `job.contractor` หรือ "ทีมติดตั้ง"
  - **แก้ขั้นงานติดตั้งจาก Master Schedule ได้เลย** (ผู้ใช้ 17 พ.ย. 2026 "ถ้าไม่ต้องไปอยู่ที่ดำเนินการ จะแก้ไขได้ไหม เพราะบางทีเราทำแผนก่อนเข้าติดตั้งจริง") — รายงานประจำวันโชว์เฉพาะงานขั้นติดตั้ง เลยวางแผนล่วงหน้าไม่ได้ · ตอนแก้แผนมีปุ่ม "แก้ขั้นงานติดตั้ง" ใต้หัวข้องานติดตั้ง เปิด `window.DrStepTable` (ตัวเดียวกับรายงานประจำวัน · ยังไม่มีตาราง = เริ่มจาก `drWhaSteps`) · กดบันทึกแผน = เขียน `dailyPlan/{jobId}` ด้วย `savePlan` (mode เดิม หรือ project) พร้อม masterSchedule · รายงานวันแรกเริ่มจากชุดนี้ (`drBlank`)
- ตัวแก้: ใส่ "วัน" แล้ววันจบคิดให้ · เปลี่ยนวันเริ่มแล้ววันจบเลื่อนตามคงจำนวนวัน · ผู้รับผิดชอบมีรายชื่อแนะนำ (วิศวกร เซลล์ ช่าง ทีมรับเหมา ฝ่ายต่าง ๆ ลูกค้า การไฟฟ้า) · ปุ่มคืนแม่แบบ/ทิ้งที่แก้ใช้ `askConfirm`

## ทดสอบ
- ใช้ฐานในหน่วยความจำสำหรับ path ที่มี `__fake` + กันเขียน path อื่น แล้ว mount `DetailDrawer` + `ConfirmHost` ด้วยงานปลอม `type: "project"` (ดู `docs/job-drawer.md`) · ใส่ `dailyPlan/__fake` ปลอมเพื่อดูแถวงานติดตั้ง

## แม่แบบ EPC S-Curve + ส่งออก Excel/PDF (ผู้ใช้ 17 พ.ย. 2026 ส่งไฟล์ `02092025_Project Schedule_Tissin food 717.60 kWp.xlsx`)
- ผู้ใช้เลือก: แม่แบบเปลี่ยน **ทั้งสองที่** · น้ำหนักใช้ **% Weight ตามไฟล์** · เส้นจริง **จดภาพรวมรายวันอัตโนมัติ**
- `MS_TEMPLATE` = หมวด A Permission Work (10.5) · B Engineering (6) · C Procurement (35) + หัวข้อ link install · แถวมี `w` (% น้ำหนักต่อทั้งโครงการ) และ `dur` (วันจากไฟล์ — ใส่วันเริ่มแล้ววันจบคิดให้)
- ตารางขั้นงานรายงานประจำวันงานโครงการ (`DR_WHA_TREE` daily.jsx) = หมวด D Civil Work (20) · E Electrical Work (28.5) ขั้นย่อยมี `w` (หัวข้อไม่ใส่ w ไม่งั้น drRollup ของ LINE เปลี่ยน) · งานเก่าที่มีตารางแล้วไม่เปลี่ยน
- หัวข้อ install ใน Master Schedule แตกเป็น **หัวข้อของตารางขั้นงาน = หมวด, ขั้นย่อย = งาน** (`msInstallRowsOf`) · เลขแบบไฟล์ A, A1 (`msLetter`) · ตัวแก้มีช่องน้ำหนัก + ผลรวม (ควร 100) · น้ำหนักขั้นย่อยติดตั้งแก้ในกล่อง "แก้ขั้นงานติดตั้ง"
- น้ำหนักใน `msCompute`: มี w ใช้ w · ไม่มีเลย = ตามจำนวนวัน (แผนเก่า) · มีบ้างไม่มีบ้าง = แบ่งส่วนที่เหลือจาก 100 ตามจำนวนวัน · `r.wp` = % ต่อทั้งโครงการ
- **S-Curve** (`msCurve`): สัปดาห์ จ–อา เริ่มสัปดาห์ที่โครงการเริ่ม · แผน = น้ำหนักกระจายเท่ากันทุกวันในช่วงแผน (งานไม่มีวันไม่อยู่ในเส้น) · จริง = `masterScheduleHist/{jobId}/{YYYY-MM-DD}` = % รวม (การ์ด MsCard จดเมื่อ % วันนี้ไม่ตรงที่จด · เฉพาะงานที่ทำแผนแล้ว) · ก่อนเริ่มจดประมาณจากรายงานประจำวัน (`msEstHist` · งานนอกตารางขั้นงาน = min(% ตอนนี้, % ตามแผน ณ วันนั้น)) จุดกลวง · สัปดาห์ที่ยังไม่ถึงไม่มีค่า
- กราฟ `msCurveSVG` ใช้ทั้งบนจอ (MsSCurve ใต้แกนต์) และหน้า 2 ของ PDF A3 · PDF มีคอลัมน์ %W
- **Excel** (`msExportXlsx`): ชีต Master Schedule แบบไฟล์ตัวอย่าง (No · Item · ผู้รับผิดชอบ · % Weight · Day · Start · Finish · % Progress · สถานะ + คอลัมน์ W รายสัปดาห์ = % ของงานนั้นในสัปดาห์ ระบายสีช่วงแผน + แถวสรุป ESTIMATED WEEKLY / ACCUMULATE / ACTUAL / DIFF) · ชีต S-Curve ตาราง + **กราฟเส้นของ Excel จริง** — xlsx-js-style เขียนกราฟไม่ได้ จึงเปิด zip ด้วย `XLSX.CFB` เติม chart1/drawing1/rels/Content_Types เอง (`msAddChart`) · ค่าที่ยังไม่มี**ห้ามสร้างเซลล์ว่าง** (Excel วาดเป็น 0) · ตรวจแล้วเปิดใน Excel จริงได้ กราฟ 2 เส้น

## วันทำจริง · เสร็จก่อน/ช้ากว่ากำหนด (ผู้ใช้ 17 พ.ย. 2026 "ถ้างานไหนทำเสร็จไปก่อนแล้ว หรือทำช้ากว่ากำหนด จะต้องระบุยังไง" → "ทำเลย")
- แถวมี `actStart` `actEnd` (บันทึกใน masterSchedule) · ตัวแก้มีช่อง เริ่มจริง/เสร็จจริง — **ใส่ % แล้วเติมให้เอง**: >0 ครั้งแรก = เริ่มจริงวันนี้ · 100 = เสร็จจริงวันนี้ · ลดจาก 100 = ล้างวันเสร็จ · แก้วันเองได้ (บันทึกย้อนหลัง)
- ขั้นงานติดตั้งดึง actStart/actEnd จากตารางขั้นงานรายงานประจำวัน · หัวข้อ = เริ่มจริงแรกสุด / เสร็จจริงล่าสุดเมื่องานย่อยเสร็จครบ
- สถานะ (`msStLabel`): เสร็จก่อน N วัน · เสร็จตามกำหนด · **เสร็จช้า N วัน** (`st = donelate` สีแดง นับรวมในช่องเสร็จแล้ว) · ล่าช้า N วัน (ยังไม่เสร็จ เลยวันจบแผน นับถึงวันนี้) · เสร็จแต่ไม่มีวันเสร็จจริง = "เสร็จแล้ว" (ข้อมูลเก่า)
- แกนต์: แถบแผน (บน) + **แถบทำจริงบาง ๆ ใต้แผน** เขียว / แดงเมื่อเลยวันจบแผน · ยังไม่เสร็จลากถึงวันนี้แบบจาง · PDF มีคอลัมน์ "ทำจริง" + แถบเดียวกัน · Excel มี Actual Start/Finish + ผลต่าง (วัน: + ช้า / − เร็ว) + ช่องสัปดาห์เขียวเข้ม = ทำจริงในช่วงแผน แดงอ่อน = ทำจริงนอกช่วงแผน

## แม่แบบตั้งต้น = แผนงาน Patouch (ผู้ใช้ 22 พ.ย. 2026 "อยากใช้ฟอร์มนี้เป็นฟอร์มเริ่มต้นของทุกๆ งาน" · เลือก "แบบ 1")
